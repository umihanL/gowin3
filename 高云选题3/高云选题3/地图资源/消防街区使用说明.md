# 消防救援薄墙街区使用说明

> 本文是早期版本的操作记录。当前启动器打开 V6 大字楼牌地图，文件为 `rescue_maze_v6/community_fire_rescue_v6.blend`。请优先阅读 [V6 使用说明](rescue_maze_v6/使用说明.md)，不要按下文的旧模型名称和尺寸选择文件。

## 从哪里打开

双击本目录的 `打开消防街区.cmd`。它会用已经安装的 Blender 打开 `community_fire_rescue_maze.blend`。

也可以启动 `D:\仿真工具\Blender\blender.exe`，选择 File → Open，打开此 `.blend` 文件。所有使用的图片已经打包在 `.blend` 内，移动单个场景文件也不会丢失这些贴图。

本次新地图叫 **community_fire_rescue_maze**。目录里原有的 `community_fire_map.*` 是之前的无贴图基准场景，二者不是同一版布局。

## 场景内容

- 12×8 米地面，真实米制比例。这个尺寸是工程假设，不是赛事指定尺寸。
- 6 厘米厚的薄板墙，内部墙高 85 厘米、外圈墙高 70 厘米。居民楼只印在墙面，没有实心楼体挡住视野。
- 三个居民楼围合区，留有出入口；双面墙纸包含居民、求助者、火焰和消防员。
- 一个独立停车区域、三个车位、P 标牌和入口道闸。
- 红黄绿三色信号灯、斑马线、道路边线和中心虚线。
- 施工横栏、锥桶、施工绕行牌。中央北向道路被封闭，可从东侧绕行。

道闸关闭时轴心高度为 0.25 米，杆件底部约 0.213 米，能与假定高度 0.28 米的小车车体相交。今后换成真实小车尺寸时，还需重新核对杆高、摄像头和车体碰撞范围。

## 第一次查看

1. 默认是全景相机，能看到整张地图。贴图首次加载可能稍慢。
2. 按小键盘 `0` 在相机视角和自由视角之间切换；鼠标中键拖动旋转，滚轮缩放，Shift＋中键平移。
3. 如果只看到灰色模型，把鼠标移到三维窗口，按 `Z`，选择“材质预览 / Material Preview”。
4. 右侧 Outliner 按功能分组：薄墙、双面壁纸、停车区、道闸、红绿灯、施工路障、相机等。点击集合名前的箭头展开。

## 播放道闸和信号灯

底部时间轴范围是 1—300 帧，30 帧/秒。鼠标放在三维窗口或时间轴，按空格播放/暂停。

- 第 1 帧：道闸关闭，红灯。
- 第 110—205 帧：道闸打开；第 96—220 帧为绿灯。
- 第 221—250 帧：黄灯，道闸正在关闭。
- 第 251 帧以后：道闸关闭，红灯。

打开文件时停在第 145 帧，道闸打开。要直接看落杆状态，把底部当前帧输入框改成 `1`。

`GATE_PIVOT_道闸转轴_播放时间轴` 是真正的旋转中心。编辑它的局部 X 旋转可以抬杆或落杆；关键帧角度为 0° 和 82°。杆件、条纹和反光端帽已经绑定到同一个转轴。动画不会自动检测小车接近，也没有电机动力学。

## 切换到小车视角

在右侧 `09_相机_CAMERAS` 集合里选中相机，把鼠标移回三维窗口，按 `Ctrl＋小键盘0`，将所选相机设为当前相机；再按小键盘 `0` 查看。

- `CAM_01_全景`：完整地图。
- `CAM_02_车载火场_0.48m`：相机高度 48 厘米，朝向有火情的墙面。
- `CAM_03_停车道闸_0.48m`：从车道观察停车入口。
- `CAM_04_正俯视`：检查道路布局。

选中 `ROBOT_CAMERA_RIG_移动车载视角`，使用 `G` 移动，`R` 然后 `Z` 改变朝向。第二台相机跟随此参考节点。此节点仅用于设置相机位置，不是带车轮和控制器的机器人。

## 修改模型和图片

选中墙板后，按 `G` 移动、`R` 旋转、`S` 缩放，按 `N` 可查看尺寸。墙体和墙纸是分开的对象，手动调整时请同时选择对应的墙体与双面墙纸。按 `Ctrl＋S` 保存；大改前用 File → Save As 另存一份。

可复现的布局源文件是 `rescue_maze_config.json`；Blender 构建脚本是 `build_rescue_maze.py`。重新运行脚本会按配置重建同名输出，并覆盖手工改过的同名场景，所以应先另存手工版本。

墙面 PNG 在 `assets/textures/`，整张地面 PNG 在 `assets/road_wallpaper.png`。如果想让 Claude Code 重画，给它 `CLAUDE_TEXTURE_HANDOFF.md`。替换外部 PNG 后，需要重新载入并打包图片，或重新运行构建脚本；旧 `.blend` 内已打包的图像不会随磁盘 PNG 自动更新。

现有贴图是清晰的平面插画，用于场景验证。大幅实体打印请根据实际板材尺寸核对有效 DPI，并按交接文档提升分辨率；不要直接按 A4 默认“适应页面”打印来确定实物比例。

## 文件和适用范围

- `community_fire_rescue_maze.blend`：主文件，可编辑结构、图片、相机和动画。
- `community_fire_rescue_maze.glb`：带贴图的第 145 帧静态快照，便于导入其他软件；没有道闸/红绿灯动画和机器人控制器。
- `renders/`：全景、车载视角、落杆停车入口、俯视图。
- `rescue_maze_validation.json`：假定小车尺寸下的静态平面净空检查，不等于轮式小车动力学或实际行驶测试。
- `rescue_maze_build_report.json`：构建信息、相机、已打包贴图和碰撞几何清单。
- `CLAUDE_TEXTURE_HANDOFF.md`：后续美术贴图交接说明。

Blender 适合制作地图、编辑贴图、安排相机并生成视觉图像。目前没有接入小车控制程序、轮胎摩擦、传感器噪声或实际避障算法。需要真正跑机器人时，可以继续接入 Webots 或 Gazebo，但必须使用这版新地图的几何，不能直接复用旧版 `community_fire_map.wbt/.sdf`。
