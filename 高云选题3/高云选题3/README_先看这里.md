# 高云选题3：源码＋当前编译产物

本包保留此前核对过的完整本地 FPGA、RDKX5、上位机源码及配置，并补回当前可用的编译/发布文件。

## 编译产物位置

- FPGA：`本地当前源码/ov5640/impl/pnr/ov5640.fs` 为当前烧录文件；同目录带 .bin/.binx、.pr 布线数据库、.db/.p 及报告。`impl/gwsynthesis` 保留综合网表和报告，`impl` 根目录保留构建输入/结果记录。
- Windows 上位机：`上位机_直接运行/消防救援演示台.exe`。请保持同目录的 DLL、配置和许可文件在一起，电脑需要 WebView2 Runtime。
- RDKX5：`X5当前编译产物/ros2_ws/install` 是从板端只读复制的当前 ROS 2 安装结果；`build` 保留对应构建结果；`src` 中保留正在使用的三个 native .so 模块。没有重新编译或停止服务。Linux执行权限记录在ZIP中，若由Windows解压后上传，需按需要恢复脚本/程序的执行权限。

## 版本与依赖

当前 .fs 与最新已有烧录记录的 SHA256 一致；上位机 EXE 与发布 BUILD.json 一致。源码完整性记录在“源码完整性核对.json”，产物和文件校验见“编译产物清单.json”及“文件清单_SHA256.json”。
本地消防员导航改造尚未完成联调/部署；本地开发源码和 X5 当前部署/编译结果分别保留，不能据此认为未部署改造已在运行。

为满足200MB以内，本包不包含模型权重、训练数据集、完整ROS/Ubuntu系统、Gowin/WebView2等工具链或第三方离线依赖安装包。源码和本项目当前编译产物均已包含，但完整运行仍需要原有依赖/模型环境。这是工程备份，不是系统镜像。

此次仅整理压缩包，未删除原工程文件、烧录、部署或操作硬件。
