## 修复和优化

- 区域导航收到DONE后继续等待实际停车与位姿，不再误取消；旧任务迟到回包不能复活已取消任务。
- FPGA报告外部运动后使旧起点失效；编号点到达后的新鲜实际位姿可以接续区域任务。
- 自检优先读取真正的拓展UART链路，避免把旧演练桥误当成串口故障；分别报告双轴参考、实际角度、音响与B13状态。
- 一次发布周期复用同一份编码器反馈，减少重复复制，也避免同批状态来自不同回包时刻。
- 旧独立预览页隐藏后停止拉图、取消未完成GET、不续租；回到页面恢复。正式上位机原本已有后台停流。显式画面开关与画质不变。
- 固定相机启动会选择明确指定的配置或已存在的本地标定，不再永久使用未标定模板；损坏或未标定的本地配置明确报错。
- 固定相机锁定检查实际喷嘴射线误差；当前驱动可达格点无法满足要求时明确报告分辨率不足，避免无限微调。
- 补充独立固定相机落点补偿接口和喷水判定，不再要求固定相机伪造旧式“画面居中锁定”。无实测表时仍只计算几何方向，不给出喷水候选。
- 固定相机搜索只观察当前视场，不再转动喷嘴扫描，也不等待喷嘴就位才能观察。缺图或过期图不会被当作“已确认无火”；检出后自动瞄准仍经过完整门控。

新落点表的数据字段、独立验证样本和调用方式见 [固定相机实测落点接口](固定相机实测落点接口.md)。

没有更换模型权重、降低图像分辨率、JPEG质量、检测类别或放宽锁定精度。电脑测试耗时不等于X5帧率；性能审查见 `performance.md`。

第一条命令逐文件隔离执行，默认最多并行3个进程，并关闭真实ROS/ASR测试开关。它是电脑开发验收入口，不是车载启动入口。第三条只生成几何误差报告，假设的尺寸只在内存中，不会生成活动标定或发出任何动作。

后续部署并连接X5后，只读自检入口为：

```bash
cd /root/rescue/ros2_ws
export ROS_DOMAIN_ID=0 ROS_LOCALHOST_ONLY=0
source env.sh
python3 tools/self_check.py --seconds 10
```

这条自检不发控制命令。PASS只表示该项软件条件满足，WAIT表示尚未启用/观测/标定，WARN表示需查看原因。

## 你怎样逐步演示

1. 接通并更新X5后，上位机连接X5当前IP的8090端口。电脑和X5同一个手机热点即可，不需要互联网。EXE是车载页面的外壳，电脑端更新不等于X5更新。
2. 先开启拓展1，看真实YOLO画面，在聊天框输入“分析当前火场”。先检查文字答案，再确认音响播报全文。
3. 用“收声测试”检查转写；它不执行小车动作。正式收音说相同问题，点击“说完提交”，连续重复三轮，确认每次都能结束、转写、回答与播报。
4. 导航演示切拓展2，在实际起点确认车头方向。例如“你现在在8号点位，车头朝地图左侧，请导航前往至4号点位”。文字与语音转写共用规则；导航不等待Qwen。
5. 确认到达由本次DONE、停车和新位姿共同给出，随后观察YOLO。抬起或搬动车后重新确认位置和朝向。
6. 固定双目、喷嘴和各项实测标定完成后，才测试“瞄准第1个火焰”；观察编码器实际角度与目标角。喷水命令独立为“开始喷水”“停止喷水”，开始是限时短喷，不是无限开水。
7. A/B/C/D区域“搜寻并灭火”还需要相机到车体、地图配准、车体余量、时间同步和喷水有效范围等实测资料。普通点位导航通过不代表整套自动灭火已通过。

## 能否软件估一个标定，每次上电固定命中

仅靠软件假设不能保证。双目先给出目标相对于相机的三维位置；还要知道相机到云台的旋转和平移、转轴位置、喷口位置和方向，才能计算喷嘴角度。水流另外受重力、压力、喷嘴和泵工作状态影响。

本次离线假设显示：1米处水平零位错1°，射线偏差约17.6毫米；当前已验证的ZDT控制格点约0.9°，最坏半格误差0.45°在1米处约7.85毫米。现有2毫米/0.3°门槛不能对所有方向都满足，程序不会改大容差来声称命中。可在实机确认更细定位能力、选择适合的观察位置或使用合适减速机构后再验收。

实际需要按顺序完成：

1. 固定相机和喷嘴结构；确认俯仰正计数对应实际向上，水平范围左右90°、俯仰0～60°与安装一致。
2. 采集真实双目标定照片及格长，用未参与标定的已知距离验收米制深度；检查左右眼对应与同步。
3. 测量相机到云台外参、两转轴偏移、喷口偏移和喷射方向。先无水验证不同距离、方位的几何指向。
4. 在受控接水目标上记录不同距离、水平/俯仰角的实测修正量，另留独立样本验证水流落点；保持同一喷嘴、压力和泵设置。新固定相机落点表不接受旧随动相机的像素补偿表，也不向测量区域外推算。
5. 每次上电恢复同一机械参考。现在没有已验收的自动回零开关，需手工摆到可重复的零位并读取编码器；更可靠的方案是机械定位/回零传感器。新启动参考有新ID，必须重新验证绑定，不能照抄旧ID。

`capture_mixed_reference.py`只记录实际参考，不完成相机外参或水流标定。目前俯仰正方向未完成现场验收，捕获工具仍限制该轴。此次所有模板保持未标定、泵禁用；本地虚拟数据不写入 `*.local.json`。
