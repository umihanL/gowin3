# 固定相机实测水流落点接口

此接口用于“相机固定在车身、二维云台只带喷嘴”。当前模板 `config/fixed_camera_landing.template.json` 未标定，所有参数为空；本次只完成本地代码和合成回归，没有水流测试或硬件输出。

## 数据与测量

直接测量需要加到几何角度上的水平/俯仰修正，不推测出水速度、水压或重力参数，不使用旧版随云台转动相机的落点像素表。

网格坐标为 `nominal_pan_deg`、`nominal_tilt_deg`、`nozzle_distance_m`。前两者来自固定相机几何求解器，距离是名义喷嘴射线的前向距离，不能填相机Z深度或双目欧式距离。每维至少两个不同值，必须覆盖所有组合（最少8个角点）。单位分别为执行器关节角度与米。

每个 `measurements` 条目必须包含：

| 字段 | 意义 |
|---|---|
| measurement_id | 唯一实测记录编号 |
| measured | 实际完成水流测量后才能设true |
| nominal_pan_deg / nominal_tilt_deg / nozzle_distance_m | 名义角度与喷嘴距离 |
| angle_correction_deg | `[水平修正,俯仰修正]`，直接加到关节角命令 |
| measured_impact_error_m | 实测落点相对目标的三维误差向量 `[x,y,z]` |
| measured_encoder_error_deg | 该次实测中，编码器相对修正目标的两轴误差 |

`independent_validation` 每个网格单元至少一个**严格在单元内部**的独立水流测试点。使用上述字段，但以 `commanded_angles_deg` 代替 `angle_correction_deg`；其值必须等于当前网格插值的名义角+修正角。验证编号不能与标定样本重复。验证失败或缺少单元验证，整个标定不加载。

所有实测落点误差必须在 `acceptance_radius_m` 内，编码器误差必须在 `water_impact_angle_tolerance_deg` 内。后者必须为实际验证过的容差且不超过0.3°；不得为适配电机分辨率而随意增大。角度修正、落点误差和容差均须填写实测数据，不能复制回归测试中的SYNTHETIC数据。

## 标识与调用

表必须绑定 `geometry_calibration_id`、`stereo_calibration_id`、`actuator_reference_id`、`pump_setting_id`、`camera_nozzle_mount_id`，另有表自身 `calibration_id` 与 `measurement_session_id`。水泵设置、安装、双目标定或启动参考变化时，旧表不能直接继续使用。

执行器配置 `pump` 中的 `setting_id`、`fixed_camera_landing_calibration_id`、`geometry_calibration_id`、`camera_nozzle_mount_id` 必须与表一致；执行器本次参考必须一致。每次capture生成新reference_id后，需要重新验证与绑定，不自动忽略ID差异。

ROS2 `fire_aim` 的独立参数为 `fixed_camera_landing_config`。`local_fire_control.launch.py` 已提供此参数，默认加载未启用模板。没有有效表时只允许几何瞄准建议，不能成为喷水候选；已启用表若遇越界或错配，则输出无效结果和空命令，不回退成旧版像素控制。

## 输出与锁定

`geometry_target_deg` 是未补偿的几何目标角；`corrected_target_deg` 是实测表修正后的连续目标角；`servo_reference_target_deg` 是在保持精度门槛下可实现的最终执行器目标。FD8等离散步进会额外核验格点角误差与补偿后出射射线的跟踪误差。无法满足门槛时明确返回分辨率不足。

补偿后的水流方向通常不会直线穿过火源，因此跟踪检查针对实测修正后的出射方向。`actual_ray_error_m` 仍记录当前直线射线到原目标的误差，`actual_tracking_ray_error_m` 记录当前射线到补偿目标射线的误差；后者保持原2mm门槛。程序没有宣称水流沿直线飞行。

只有新鲜目标、匹配的选中火源、本次实测编码器、全部标定和泵设置一致，且修正目标稳定锁定后，才给出 `pump_candidate=true`。`image_locked` 永远为false，执行器使用独立的固定相机 `geometry_locked` 门控。当前喷射是否真正命中无法仅凭标定得知，因此 `physical_hit_verified` 与 `pump_allowed` 在视觉提案中始终为false。最终有限时长喷水仍由执行器的停车、授权、目标绑定和失败关水逻辑决定。

主要拒绝原因：

- `fixed_camera_water_impact_unmeasured`：没有完成实测表。
- `fixed_camera_landing_outside_measured_grid`：任一角度或距离越出实测域，禁止外推。
- `fixed_camera_landing_geometry_reference_mismatch`：几何、双目或编码器参考不匹配。
- `fixed_camera_landing_active_profile_mismatch`：当前泵/安装/参考/标定配置不匹配。
- `fixed_camera_compensated_target_outside_limits`：修正角超机械限位，禁止夹紧后冒充成功。
- `fixed_camera_actuator_resolution_insufficient`：电机格点无法达到原精度门槛。

这些拒绝均不能授权喷水。恢复实际自动灭火前，需要完成真实双目标定、固定安装几何测量和上述独立水流验证。
