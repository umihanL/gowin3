## 这次修复的视觉问题

原扫描方向与正常相机画面不一致，会把车道横向偏差和前方道路方向混淆。现在在正常相机图像的近、中、远三条**水平线**上找黑色连续路段；近处中心相对图像中心为横向偏差，远近中心之差为方向偏差。

全黑、全白、贴住图像边界和不合理宽度的黑段不作为可靠道路。弯道远端离开视野时，近处与中间两条有效线仍可估计局部方向；只有一条有效线时退出视觉控制。`vision_video` 的扫描行和横向基准已做成参数，默认近/中/远为 68/54/40、中心列 52（缩略图坐标）。这些默认值不是相机的米制标定结果。

原有视觉 PD 和滤波继续生效：横向 0.5°/缩略像素、方向 1°/像素差、低通微分 0.25；直线视觉限幅 ±12°，圆弧叠加修正限幅约 ±4°，每 10 ms 最多改变 0.5°。连续三帧有效才接入，250 ms 无更新或道路无效后平滑退出。绕障、终点附近及侧激光小于 10 cm 时保留现有仲裁。

导航在较大转角处将速度上限逐级降为 150 / 110 mm/s，并沿用原来的速度变化限制，给舵机和视觉控制留下响应时间。遥控、手动、减速停车、绕障状态机和它们的速度设置未改。

路线前视距离从 140 mm 调为 100 mm，减小圆弧跟踪时的偏差；同一条生成路线、自行车和舵机响应模型中，最大车头横向误差由约 48 mm 降至约 34 mm。它仍是仿真模型结果，未包含真实相机安装误差、车轮打滑和转向连杆误差。

视觉目前纠正转向，不提供地图绝对坐标。只调整 PD 不能替代相机投影标定、舵角标定或正确的道路几何。当前仿真通过不等于已经在实车上证明全程居中。

## 请测量这些相机参数

将车放在水平地面，车轮回正、相机固定。以**车头中点的地面投影为原点**，向前为 X 正方向，向左为 Y 正方向，单位 mm。

| 项目 | 如何测量 |
| --- | --- |
| 镜头高度 H | 镜头光心到地面的垂直距离，量镜头中心，不量开发板边缘。 |
| 镜头前后位置 Xc | 镜头光心的地面投影距车头中点多少；在车头后方填负数。 |
| 镜头左右位置 Yc | 镜头相对车身中线的偏移；左侧为正、右侧为负。 |
| 光轴向下俯角 | 从水平线向下量；水平为 0°，垂直看地为 90°。不是简单记录 PCB 与地面的夹角。 |
| 偏航与画面倾斜 | 镜头是否向左/右偏，画面是否绕光轴歪斜；分别记录方向和角度。 |
| 图像—地面对应点 | 见下一段；用于直接求地面投影，是精度标定的关键。 |

建议在车头前方 **200、400、600 mm** 处，各标出车身中心线及左右 **100 mm** 的点，形成 3×3 地面标记。距离可根据实际视野调整，必须都能看见。保持车辆和相机不动，保存正常相机的完整 **640×480 图像**，标出每个点在图像中的位置：左上角为 (u=0,v=0)，向右 u 增大、向下 v 增大。每点提供 `(X,Y,u,v)`；至少四个不共线点，六到九个更利于校验。也可以把可辨认的标记照片和各标记实测地面位置一起提供。

如果无法导出相机原图，可在“实时数据 → 原始图像”页正对屏幕拍清晰照片，保留显示画面四角，便于先纠正拍屏透视；不要只拍缩略二值图。屏幕正常页左右各有 80 像素边栏，标定使用中间 640×480 相机区域。

高度、位置和俯角能改进几何模型；要精确换算厘米，还需要上述对应点，或者相机焦距、视场角和畸变标定。若画面边缘明显弯曲，再用**多个不同姿态、不同位置的棋盘格照片**标定镜头畸变，单张正视照片不足以可靠估计全部内参。

另外记录：最窄路宽、各弯道道路中心半径，以及舵机 20/55/90/125/160° 时前轮实际转角。车辆已知参数继续使用：轮径 66 mm、轴距 138 mm、车长 300 mm、后轮距 168 mm、前轮距 175 mm。满舵实际行驶一圈时，测后轴中点与车头中点的轨迹半径，可校验转向模型。

## 验证

`python sim/run_vision_tests.py` 检查颜色与方向、等比例坐标、阈值真正改变像素、同帧双缓冲、道路扫描、远端丢失、PD 收敛、过期回退和显示流水线。连续光栅测试对正常与竖屏预览区实际比较 706720 个 RGB 像素，另检查 DE/HS/VS、行帧边界和消隐。原有制动回归保留。

`python sim/run_centerline_tests.py` 检查地图选点、规划后点位标记回写、路线 RAM、禁行挡板、真实路线与编码器/IMU 自行车模型、原有绕障和车头参考点逻辑。`python sim/run_global_road_tests.py` 用独立的“节点×路径点进度”Dijkstra 与 RTL 比较完整路线最短代价，覆盖重复道路、重复点位、路口/圆弧吸附区域和最多八个路径点。

另外将 RTL 实际发布的六路径点路线和强制经过 S 弯的路线输入车辆运动模型：六点路线最大车头横向误差约 24.6 mm、终点误差约 9.6 mm；S 弯路线对应约 20.6 / 14.4 mm。结果分别在 `sim/road_curved_motion.log`、`sim/road_s_motion.log`。这些数值衡量模型里的车头轨迹，不是实车误差或完整车身不压线的保证。
