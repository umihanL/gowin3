# 横屏视频与阿克曼导航

当前版本已改用固定直线、圆弧道路网络，取消下文旧版 A* 和迭代平滑流程；二值预览页也已改为竖屏观看。当前实现和操作请先看 [中心线导航说明](centerline_navigation.md)。下文保留地图来源、原有界面和旧规划实现的历史细节。

## 视频与界面

TFT 使用原生 **800×480 / 33 MHz 横屏**。摄像头输出 **640×480**，原样显示在 `x=80..719, y=0..479`，左右各 80 像素黑边，保持完整 4:3 视野，不裁切、不拉伸。旧版 480×800 ISP 缩放和竖屏 DDR 转置已取消，图像相对旧版恢复横屏方向。

保留原有 Gowin DDR/FIFO IP、双帧缓冲和垂直消隐换帧。跨时钟邮箱改为 4 行，640 像素宽度仍能放入原有 BSRAM；黑边不消费 FIFO。菜单覆盖视频时仍读取隐藏的视频。IMU 姿态叠字在视频右上角，SPI、姿态计算和校零流程保留。

显示和触摸均直接使用原生 `u=x, v=y`。主菜单两行两列：实时数据、遥控模式、实时避障、自主导航。避障子菜单为障碍物检测、自动减速停车、自主绕障。

自主导航 → 路径设置：左侧地图，中间按钮，右侧坐标和路程。先点起点/终点/路径点，再点击地图。绿色“起”、红色“终”各一个，可重新设置；蓝色编号路径点最多 8 个，按添加顺序经过。所有位置可视化，坐标对应**车头中点**，世界原点为地图左下角。不可通行触点可向最近安全单元吸附 8 cm；相邻点长轴间隔至少 20 cm、另一轴误差不超过 8 cm 时，自动对齐横线或竖线。对齐落点仍检查地图，若阻挡则保留原安全点。屏幕显示采用后的坐标和标记。

规划完成显示最终路线和路程。修改点会使路线失效；清除或返回可取消规划。转弯半径不足仅提示并允许开始；普通地图车身碰撞风险已取消。明确禁行挡板、无路、节点溢出仍阻止无效规划。路径设置右下可选择禁行挡板，依次点击两端，最多四条。动态绕障和参数见 [自动运动说明](auto_motion.md)。

## A* 与弯道

`astar_grid.v` 使用八邻接，轴向代价 5、斜向代价 7；已删除非中心区域和车身轴向提示的附加代价。启发函数为可采纳的 `5*max(dx,dy)+2*min(dx,dy)`。斜向扩展要求两侧正交格同时可通行，禁止切过障碍拐角。当前最短路已与独立 Dijkstra 比较。每格仍占 18 bit：2 位状态、3 位父方向、13 位代价，避免扩成四倍航向 RAM。

开放集串行扫描，每次扩展约 28160 周期。当前规划参考图约 4000 个自由单元，33 MHz 下单段扫描上界约 3.4 s，另加清图和后处理；8 个路径点最多 9 段。代价约 8180 以上报超限，期间可触摸取消。

`nav_control` 反向发起各段搜索，使回溯节点按驾驶顺序进入 `nav_path_refiner.v`。后者最多缓存 2048 个节点，合并重复段接点，固定起点、终点和用户路径点，执行 512 轮受规划地图限制的邻点平均平滑，坐标采用每 cm 256 单位。总节点超出容量会明确拒绝，不截断路线。

平滑后按三点外接圆估计局部半径，提示半径小于 205 mm、零长度内段及切线反向的路线。已取消普通地图占据单元和地图边界的整车碰撞风险提示；19×30 cm 车身矩形采样仅保留对显式禁行挡板的硬检查，附加 8 mm 栅格采样余量。曲率风险仍输出完整有序节点与路程；显式禁行挡板冲突不发布路线。三次线段长度计算复用同一对平方乘法器。

车辆参数集中在 `src/vehicle/vehicle_config.vh`。轴距 138 mm、后轮距 168 mm、轮径 66 mm，左转 36°/右转 34°；后轴工作最小半径约 205 mm，车头轨迹半径还包含 228 mm 偏置。现有曲率提示仅保留宽松的 205 mm 下限，不代表完整车头路径的可行性证明。舵机端点为 160°/20°，中间暂按线性。车长 300 mm、后悬 72 mm，所以后轴至车头 228 mm、前轴至车头 90 mm。修改几何后执行 `tools/generate_vehicle_assets.py` 同步差速表与元数据。

这是**栅格 A* + 平滑 + 曲率提示**，不是完整 Hybrid A*。普通车身碰撞提示已取消，没有自动重新搜索其它静态路线，也未实现固定起终航向、倒车或连续车体扫掠求交。执行层采用 140 mm 前视距离、2 mm 横向死区和转向变化速率限制；直线小转角跟踪时，仅单侧距离小于 100 mm 才附加 3° 远离修正。保留直线段动态绕障。地图可通行不等于实车无碰撞保证；仍需标定车体、地图和实际转角。初始车头应与首段切线一致。

## 接口

| 接口 | 含义 |
| --- | --- |
| `operation_mode[3:0]` | 0 主菜单，1 实时，2 遥控，3 避障菜单，4 导航菜单，5 地图，6 检测，7 减速停车，8 避障，9 导航 |
| `navigation_request` | 有效路线开始导航后保持，停止或返回清除 |
| `route_valid` | 所有路径段完成且无显式禁行挡板冲突，并且没有编辑点；曲率警告允许发布 |
| `navigation_ui.path_valid/path_x/path_y/path_segment` | 最终路线顺序流，2 cm 网格坐标 |
| `navigation_ui.path_x_q8/path_y_q8` | 内部完整平滑坐标，每 cm 256 单位，Y 从图片顶部向下 |
| `nav_path_refiner.sample_*` | 有序平滑节点接口，供后续跟踪控制器存储 |
| `nav_control.astar_trace_*` | 平滑前网格路线，不是最终可驾驶路线 |

最终节点保留在 refiner 的原有路径 RAM 中，新增 `execution_*` 读口供整车控制和路径段预估复用，无需复制一份路径 RAM。显示位图只记录位置，不保留方向、段序或重复访问次数。复位会清除用户点和路线，静态地图 ROM 保留。

## 验证

本次未改 SCCB、DVP、视频传输、GT911、Gowin DDR/PLL/FIFO IP、PS2、七通道 UART、ToF 协议、CST 或 SDC。IMU 更新连续异常的局部恢复及编码器短时补偿；电机包装模块增加 TB6612 短路制动，PI 算法、极性和编码器逻辑不变。车头导航、点选对齐及 400 mm/s 下的 25 cm 制动回归见 `python sim/run_nose_tests.py`。

python tools/generate_vehicle_assets.py
python sim/run_vehicle_tests.py
python sim/run_navigation_tests.py --snapshot
python sim/run_portrait_tests.py --full
python sim/run_fix_tests.py

powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
