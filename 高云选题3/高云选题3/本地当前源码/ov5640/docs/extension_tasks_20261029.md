# 拓展任务与 X5 通信（2026-10-29）

> 本页为同日早一轮记录。任务命名、导航取消斑马线限速及新开关，以 [最新修订](extension_revision_20261029.md) 为准。

本轮修改了源码，增加了 FPGA 拓展入口、语义运动执行、独立交通任务和远程路径约束上传。**没有烧录实物；没有生成本轮新位流。** 当前 Gowin 安装目录迁至 `D:/FPGA/Gowin/`，许可配置仍引用不存在的 `C:/Gowin/gowin.lic`，运行报 `License verification failed File can not be opened`。原 `impl/pnr/ov5640.fs` 保持原样，它不包含这些新指令，不能拿旧位流测试新功能。

## 任务分工与入口

主屏底部增加“拓展1视觉对话”“拓展2语义导航”。点击会选择通信控制并进入驾驶页，保持停车，具体任务由 X5 上位机选择。原实时数据、遥控、避障、自主导航入口保留。

![FPGA 主屏](extension_home_20261029.png)

拓展1：摄像头 → X5 YOLO／语音识别／Qwen → 无线上位机。这条链不依赖 FPGA，FPGA 屏幕入口只是操作提示，不会启动 YOLO，也不会让车动。

拓展2：语音 → X5 确定参数、地图路口约束 → UART → FPGA 编码器／IMU／路径规划及电机闭环 → 回报 → 上位机。未知距离、未知当前地图姿态、未标定侧视方向不能靠大模型猜测执行。

独立交通任务：明确选择交通模式后，FPGA 相机发现斑马线 → FPGA 立即制动 → 两轮实际停止后通知 X5 → X5 看红绿灯 → 绿灯指令恢复直行。其他模式不会因 X5 斑马线算法触发此任务。已有自主导航模式的 FPGA 斑马线限速保留。

## 接线和帧

沿用 **E14 TX／E13 RX、115200 8N1、3.3 V TTL、共地**，不改变任何引脚约束。X5 的 PIN8/10 和 PIN3/5 当前已给两台步进驱动占用，不能再并接 FPGA，须另配可用 UART 或 USB-TTL。

```text
A5 5A 01 SEQ CMD D0 D1 D2 D3 CHECK
CHECK = XOR(01, SEQ, CMD, D0, D1, D2, D3)
```

多字节小端。原 01～07 指令保持。新运动命令只在明确选择的通信控制页面内执行；不是之前 X5 草案里的可变长 CRC16 帧。

| 命令（十六进制） | D0～D3 | 行为 |
|---|---|---|
| 10 定距 | int16 距离 mm，uint16 速度 mm/s | 距离非零、绝对值≤10000；速度20～200。正为前进，负为后退。仅任务模式2。 |
| 11 有限续租运动 | int16 速度 mm/s，int8 转角度，保留0 | 速度非零、绝对值≤200；转角±28°。400ms没有同SEQ续租即停；01心跳不续运动租约。 |
| 12 任务模式 | 0待机／1视觉对话／2语义运动／3交通，其余0 | 只切换任务，不启动。先停车再换非零模式；切换完成后等14 phase0再发送运动。 |
| 13 红绿灯 | 0未知／1红／2绿，其余0 | 只在交通任务有效；绿仅能放行 WAIT_LIGHT。 |
| 14 状态 | 全0 | 回复94：D0 phase，D1 flags，D2/D3剩余距离mm。 |
| 15 能力 | 全0 | 回复95：D0=0，D1版本1，D2能力0F，D3任务模式。 |
| 16 | 保留 | 不直接执行；语义路口通过20～23实现，不能把16 ACK当转弯实现。 |
| 20 起点 | uint8 grid_x、grid_y，其余0 | 清除旧途经点／终点，进入地图页；只设置，不移动。 |
| 21 途经点 | 同20 | 依次添加，最多8个。 |
| 22 终点 | 同20 | 设置终点。 |
| 23 规划 | 全0 | FPGA原有规划器执行，成功自动进入导航运行页；之后02速度、03 D0=1启动。 |

其他新指令回复 `CMD|80`，D0结果：0接受、1页面/模式不允许、2参数、3未就绪/过期会话、4忙、5未实现。**接受不等于完成，也不等于停稳。** 每次请求等回复；控制保持期间每≤500ms发01。

14 的 phase：0等待、1定距行驶、2续租行驶、3制动等待停稳、4定距完成、5运动故障、6等待红绿灯、7规划中、8路线就绪、9规划失败/取消、10导航运行、11导航完成、12导航故障。flags bit0扩展运动使能、bit1实际两轮停止、bit2等待灯、bit3通信控制页允许；bit3包括远程地图和导航页，但10/11另要求驾驶页。

两轮连续100ms无编码脉冲且实测速度绝对值<5mm/s才置“停止”。STOP05只取消，不发布完成；定距到目标并停稳发布F0，错误发布F1。异步格式保持旧协议：SEQ=0，D0=原运动请求SEQ（任务号），D1原因/状态，D2/D3=0。F3表示斑马线已停车，D1=1。主机同时轮询14的WAIT_LIGHT与完成状态，避免只依赖异步单槽事件。

定距使用轮径66mm、1560counts/rev，双轮增量先相加、乘定点比例、最后除2，保留奇数总脉冲的半计数。最后5cm降至40mm/s，在目标附近制动；真实停车误差需要实测轮径、滑移和制动距离标定，不能宣称毫米级到点。倒车没有新增后向测距传感器。

11同SEQ允许同方向调速（例如60→30mm/s）与转角调整；反向须先停。租约到期后迟到的同SEQ不能重启；STOP和通信恢复也不自动继续。开始新的任务使用新SEQ。所有运动持续受2s链路看门狗限制。

## 第N个路口怎样实现

使用当前真实地图的拓扑，不把相机路口计数伪装成已实现。X5 从固定车头起点和朝向把“第N个路口左/右拐”变成顺序途经点约束，FPGA 收到后仍运行现有 `nav_road_planner`，再由原 IMU／编码器导航引擎跟踪。起点姿态要与实车一致；小车移动后的下一任务不能继续套旧起点。

上传坐标就是既有规划器的2cm网格：左上角为原点、X右增Y下增；x为0～175、y为0～159。地图世界坐标近似 `x_cm=2*x+1`、`y_cm=319-2*y`。规划器会吸附到可行中心线，最终点可能与原始点击格不同。首个前向途经点约束起始方向，分支前途经点约束经过顺序。

真实 RTL 路径仿真：固定输入起点(52,140)，第1路口左转21个采样点、80cm；第2路口右转34个采样点、131cm。已检查采样连续、起始方向、途经先后和最终分支位置。它验证的是规划路径生成，不是实车完整转弯净空。现地图部分弧线曲率和实测最大转角的匹配仍需实物标定，禁止以软件仿真代替这项验收。

05在规划过程中会取消规划，迟到done也不能重新进入运动。导航完成、故障、暂停仍使用原导航语义；任务结束后12可回驾驶页准备下次任务。
