# 纯惯性导航与斑马线限速（2026-10-28）

自主导航的转向、位置估计和路径跟踪只使用 IMU 航向、编码器里程与路径规划点。移除了道路边界提取、Gaussian 车道滤波、逆透视道路校准、视觉融合转向、视觉起步判定及算法选择菜单。视觉道路数据不再连到车辆控制器。摄像头预览和二值化显示保留。

视觉在车辆控制中只提供斑马线状态。检测器从 104×78 的图像缩略图中检查画面中央靠下的多组横向亮带与暗间隔，不计算地图坐标或车辆偏航。一次有效完整帧确认斑马线后，速度目标降为正常导航目标的一半，且上限为 60 mm/s；因此 200 mm/s 会降到 60 mm/s，80 mm/s 会降到 40 mm/s。降速时每 10 ms 最多下降 4 mm/s。有效完整帧确认斑马线消失后，原来的路径和限速目标恢复，速度按原有 2 mm/s 每 10 ms 加速斜坡回升。不完整帧不清除已确认状态；这样避免漏帧误恢复。紧急停车优先于斑马线限速。

设置页的“惯性导航 / 惯导加视觉”算法选择已删除，因为系统现在只有纯惯性导航。此前加入的自主避障开关保留且默认关闭：关闭时沿规划路线受前方测距速度包络控制并停车等待，开启时才允许自动绕障。独立的实时避障任务继续保留。

## 验证

- 摄像头到车辆控制的逐像素帧仿真，检测横向多条纹，拒绝单条白线、整幅白图和暗路；检查 200→60→200 mm/s、低速减半、不完整帧保持、孤立噪点、暂停/继续、遥控模式、独立绕障和紧急停车。并确认斑马线信号不改变路线点或转向。
- 五组路线重放包含斑马线降速下的外圈左转、纯惯导外圈左转/右转、S 弯和完整照片地图。四条纯惯导轨迹输出文件逐字节一致；斑马线左转路线也正常到达终点。
- 菜单回归确认算法选项已移除，避障默认关闭、开关点击和跨页保持正常。全车动态绕障、Host/UART、IMU/编码器、测距停车和故障回归通过。
- 完整 Gowin 综合、布局布线、引脚与 Setup/Hold 检查结果以及资源余量记录在本目录的验收 JSON 和 [资源报告](resource_usage.md)。

斑马线判定仍依赖安装角度和实际画面让斑马线进入图像中央下方检测区域；相机高度不再用于定位或导航。数字仿真不能替代对实际识别距离、降速距离和轮胎制动的实车验证。此版本未烧录。
