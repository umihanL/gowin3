# 可调舵机中值（2026-10-30）

版本：`servo_center_20261030`。本轮只增加舵机中值设置和输出平移，保留纯惯导、斑马线限速、原有路径、转向方向和后轮差速。构建和验证的最终结果以同名 validation JSON 与 `resource_usage.md` 为准。

## 操作

进入主菜单右上角“设置”→“参数设置”→第五项“舵机中值”。四个按钮从左到右为 **−1.0°、−0.1°、+0.1°、+1.0°**；每次有效按下调整一次，长按不会连续累加。界面显示当前中值、允许范围以及当前输出上下限。设置立即生效，退出页面后保留；与现有设置一样只保存在 RAM，上电/复位恢复 **90.0°**，不写 Flash。

设置范围 **50.0°～120.0°**，到达边界后继续点击不会越界。这一范围由绝对舵机指令 **0°～180°** 和原有左右偏移推导，属于软件指令约束，不代表整段机械连杆行程均已实测。

## 控制关系

原始实测标定保持不变，左右分别插值，不能用一个固定传动比代替：

| 方向 | 前轮转角 | 原舵机指令（中值 90°） |
| --- | --- | --- |
| 左 | 0、8、11、15、20、24、28° | 90、100、110、120、130、140、150° |
| 右 | 0、4、11、20、26、28° | 90、80、70、60、50、40° |

运行时先按原表得到相对 90° 的舵机偏移，再以设置中值为基准输出：

`舵机输出 = 当前中值 + 左转偏移`，或 `当前中值 − 右转偏移`。

左最大偏移 +60°，右最大偏移 −50°；因此：

| 中值 | 右侧最低输出 | 左侧最高输出 |
| ---: | ---: | ---: |
| 50.0° | 0.0° | 110.0° |
| 90.0° | 40.0° | 150.0° |
| 92.3° | 42.3° | 152.3° |
| 120.0° | 70.0° | 180.0° |

前轮请求仍限制为左右各 28°，每 10 ms 最多变化 1°；后轮差速仍按前轮转角、142 mm 轴距与 168 mm 后轮距计算。中值只改变最终舵机命令，不改变路径规划的几何角度、IMU 航向、编码器里程或差速比例。触摸驾驶、遥控、通信和自主导航共用同一输出链，所以都使用当前中值。

设置值精度为 0.1°。PWM 查表分辨率为 1 μs，在当前 500～2500 μs / 0～180° 映射下，0.1° 命令能产生不同的脉宽；完整帧仍为 20 ms，仅在帧边界应用新脉宽，避免修改中途截断脉冲。机械死区、间隙和负载造成的实际角度误差不能由数字设置分辨率保证。

## 调整和实车确认

以车轮实际直行位置确定新中值，小幅调节后确认前轮回正。软件把原标定曲线整体平移，不会自动测量连杆的新传动关系；若改变了舵盘安装角或连杆结构，应重新测量左右若干转角点，再更新标定表。尤其是接近设置两端时，应先确认连杆和舵机不会碰到机械止挡；前轮角度与输出极限的准确性仍需实车验证。

## 修改位置与验证

- `src/navigation/vehicle_settings.v`：11 位十分之一度参数、默认值、范围饱和和四按钮；独立于速度与避障参数。
- `src/navigation/nav_control.v`、`navigation_ui.v`、`nav_renderer.v`：参数页第五行、页面跳转、十进制小数显示和限位显示。
- `src/vehicle/vehicle_subsystem.v`：共享参数、非线性偏移平移、独立输入钳位、随动上下限；原前轮限幅、缓变与后轮差速保留。
- `src/vehicle/motor/servo_pwm.v`：0.1° 输入、2048 项常量脉宽 ROM、原帧边界更新策略。
- `src/vehicle/vehicle_config.vh`：由原始实测标定推导左右偏移和中值范围；`servo_offset.mem` 保持原始文件。

复现：`python sim/run_servo_center_tests.py`，加 `--snapshot` 可生成界面截图；设置与电机响应回归：`python sim/run_settings_tests.py`。专用测试覆盖菜单回跳、两种步长、长按去重、上下界饱和、显示、参数隔离；生产 33 MHz PWM、全部 ROM 项、帧周期和无毛刺更新；真实设置到整车舵机输出、四个中值的全部 57 个前轮角度、原有左右差速与全车 I/O。

完整构建：`python tools/build_servo_center_20261030.py`。构建脚本冻结全部硬件输入，对比上轮源文件，仅允许本轮 10 个硬件输入变化；检查时序、引脚、地图/中心线/中文字库和 PWM ROM，随后发布默认位流和带版本名副本。尚未烧录或进行实车验证。
