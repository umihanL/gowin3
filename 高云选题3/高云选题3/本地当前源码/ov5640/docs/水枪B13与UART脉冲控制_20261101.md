# FPGA B13 水枪控制

水枪 MOS 模块控制信号由 FPGA `water_pump` 输出，CST 绑定 **B13、LVCMOS33、高电平开启**。MOS 模块 GND 与 FPGA 共地，水泵使用额定独立电源；B13 只接逻辑控制输入，不给水泵供电。X5 原物理16脚不再作为此方案的控制输出。FPGA 配置完成前的默认电平仍需由 MOS 模块/外接下拉保证，代码中的复位低电平不代表上电未配置阶段也已验证。

控制路径：上位机按钮/语音 → X5 现有动作和瞄准联锁 → X5 唯一 UART 通信节点 → FPGA E13 RX / E14 TX → B13。没有新增第二个串口占用者。这里新增的 FPGA 互锁不能替代双目标定、喷嘴落点校准或真实停稳验收。

## 协议

沿用 `A5 5A 01 SEQ CMD D0 D1 D2 D3 XOR`，校验为字节2～8异或。`0x15` 的扩展能力字节新增 `0x20` 水枪位，现值 `0x3f`；地图能力 `0x30` 仍为 `0x1f`，是另一组能力字段。

| CMD | 参数 | 回复与行为 |
|---|---|---|
| `18` | D0/D1为本次脉冲毫秒，1～1000；D2/D3必须0 | `98`普通结果码。明确单次开泵，最长1秒；已经开启再发返回BUSY=4，绝不重置计数。|
| `19` | 发送全0；固件对本指令忽略参数以优先关泵 | `99`普通结果码。任何页面均可关闭并解除锁止；发送器忙也立即执行，随后回复。|
| `1A` | 全0 | `9A`：D0为水枪标志，D1为停止原因，D2/D3为剩余毫秒。忙或参数错误返回 `FF FF FF FF`，不可作为有效状态。|

开泵前要求通信模式处于有效控制页、心跳有效、底盘没有运行请求，两个轮速连续100ms在±5mm/s内，并且已经通过 `19` 解除本轮锁止。上电复位默认关泵且锁止；通信恢复本身不启动水枪。

`9A` 的D0：bit0=B13输出寄存器为高；bit1=轮速静止窗口通过；bit2=链路有效；bit3=有效控制页；bit4=当前可开始新脉冲（不在喷水且未锁止）；bit5=锁止。bit6～7为0。**bit0不是水流传感器反馈，不能证明水泵、水压或命中。**

停止原因D1：0显式关泵/正常开启，1脉冲到时，2通信失联，3退出控制范围，4轮速或运动请求变化，5普通停车指令，6模式切换或已接受的运动命令，8复位。原因仅表示最近状态，不应当作流量反馈。

超时、断联、页面退出、运动或停车后锁止，须 `19` 再允许新脉冲，防止延迟开启请求在刚刚超时后重新点亮。X5不自动重试ON、不周期续租，过期的排队ON必须丢弃；每次动作结束发OFF。普通 `05` 停车也立即关泵。水枪高电平期间，串口 `03/07/10/11` 运动启动命令返回BUSY，防止先开泵后启动车辆。

只读 `1A` 不刷新控制心跳；失去控制心跳最多按现有2秒链路看门狗断开，但单次水枪脉冲1秒上限更早生效。即使X5进程阻塞，FPGA也会独立到时拉低B13。
