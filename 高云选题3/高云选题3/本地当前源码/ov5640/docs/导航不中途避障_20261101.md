# 地图导航不受普通障碍检测打断

用户要求：导航途中不要因避障等普通任务停下。适用范围为FPGA模式9的地图路线执行，包括编号点导航和上传路点导航。

## 修改后的行为

地图导航使用原 `ov5640666` 的道路规划、IMU＋轮编码器位姿和路径跟踪核心。进入导航后，四路测距不参与导航速度、方向或绕行选择：普通近物、40 mm近距离、无回波、测距超时或报错都不会使地图导航减速、绕行或停车。摄像头斑马线和YOLO目标也不纠正编号导航路线。

切换任务时还清除了旧避障状态的干扰：从独立避障返回地图导航，不再由上一任务的近障停车判断覆盖新导航状态。新模式进入后仍按自己的故障条件检查。

仍保留配置速度、弯道速度约束和接近终点时的减速，以完成既有地图轨迹。设置页“自主避障”固定显示“关闭”，移除开关点击入口，避免界面显示开启但控制器实际不使用。

以下情况仍会停车：

- 到达终点，或用户明确设置速度为0。
- 人工停止、取消、暂停，退出行驶页面，或显式切换任务。
- 主机通信失联。
- IMU长时间无效、编码器异常、车轮堵转。
- 路线无效、路径跟踪严重偏离或其他无法继续正确跟踪的故障。
- X5收到水泵状态不明、喷水仍开启、执行器急停/错误，或协议/任务超时。

这不是“无论发生什么都强制前进”。本变更取消的是普通障碍判断对地图导航的控制。真实物体挡在预存路线时，导航同样不会主动避停，演示应使用已清空的规划路线。

独立任务不变：模式7距离制动、模式8自主绕障以及单独开启的红绿灯任务仍执行各自功能。

X5侧只读核对：UART心跳由任务节点独立发送，不依赖电脑网页或Qwen回答；火焰居中只用于独立 `seek_fire`，红绿灯只用于交通任务。网页隐藏/关闭的停止操作只结束电机调试，不取消编号点导航。普通YOLO目标、场景问答和电脑展示连接不作为编号点导航的障碍停车条件。未新增X5运行代码。

## 文件与验证

生产改动集中在：

- `src/vehicle/vehicle_motion.v`：模式9独立速度计算；绕行与前向近障制动仅属于独立任务。
- `src/navigation/vehicle_settings.v`：导航避障兼容输出固定为0，不再可点击开启。
- `src/navigation/nav_renderer.v`：显示静态关闭状态。

修改前文件与本地RTL测试保存在 `diagnostics/nav_uninterrupted_20261101`。旧测距停车预期的测试仅适用于旧版本；新测试应证明测距不能改变地图导航，同时仍能人工暂停、正常到达和按故障停车。
