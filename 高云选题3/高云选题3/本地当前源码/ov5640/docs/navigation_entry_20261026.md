# 导航弯道入口、转向方向与出弯居中修复

这次修正三个控制问题：看到远处弯道就提前转向、直角弯目标落到车后后反向打角、出弯后残留横向偏差。硬件源码只改动导航融合、导航执行、路线预处理及其连线四个文件。

## 转弯入口

旧逻辑用两帧视觉弯道趋势加地图大转角直接接管。摄像头最近有效地面约在车头前 172mm，画面已经呈弯道时，车头仍可能在直道上；旧条件没有区分这两件事。

路线预处理现在向前提供至多 240mm 的下一弯方向、到入口距离和出口航向。执行器在这一弯第一次进入预告范围时锁存入口，结合当前目标前向距离和编码器行程判断到达，不再随每个前视目标向前移动入口。入口提前量为 8mm，用于控制/舵机响应；没有增加额外的大距离提前转弯。

短暂入口接近阶段保持来向的 IMU 航向；到入口后沿地图圆弧跟踪。即使路口图像还像直道或出现另一支路，也不能把指定左转改为右转。进入新方向的弯道时，立即屏蔽上一弯的入口状态，避免在同一控制拍读取旧值。

## 圆弧跟踪与惯导

正常圆弧仍由地图目标和实际位置闭环跟踪，不是从入口就一律打满转满 90°。已确认转弯锁存出口航向；地图短暂失配，或者追踪指令与尚未完成的出口转角相反时，由 IMU 补足剩余转角，接近出口时收小转角。目标落到车后不能自行反向兜回去追逐。

S 弯采用预处理得到的实际出口角度，按各自入口切换方向；连续同向弯在接近当前出口并确认下一段时更新出口。重新获得有效出口道路后交回视觉，保留单边有效道路的纠偏能力。未取消相机断流、持续失视、倒退、超时及超行程保护。

## 出弯居中

将 210mm 前视误差中的航向分量与车头横移分开，航向单独阻尼；增加最大约 2°的小幅横向累积补偿，克服整数转角、舵机静差造成的残留偏置。补偿带泄漏，只在新鲜、近似平行的直道数据下累积，转弯恢复和停用时清除。下游舵机的限速、40～150 限幅及实测转角映射保持原样。

独立后轴自行车模型测试中，两个方向各 80mm 的出口偏差在 100mm/s、12 秒观察窗口内分别收敛到约 0.57mm / 0.35mm。这是理想数字模型结果，不能当成实车精度承诺。

## 验证与交付

同一组公开端口故障测试在备份旧代码上复现提前满舵、转向反转和居中残差，修改后通过。新增地面投影相机模型在 188mm / 274mm 的地面扫描带取样，限制水平视野；它能暴露原先理想切线相机没有覆盖的提前转弯问题。

完整结果以 [本次验收记录](navigation_entry_20261026_validation.json) 和 [资源时序报告](resource_usage.md) 为准。下载文件仍为 `impl/pnr/ov5640.fs`。备份位于 `impl/baseline_navigation_entry_20261026/`，包含修改前源码、位流、布线检查点与哈希清单。
