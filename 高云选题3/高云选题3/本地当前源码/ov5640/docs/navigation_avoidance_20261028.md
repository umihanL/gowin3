# 自主导航避障开关（2026-10-28）

> 历史版本：2026-11-01起按用户新要求，地图导航不再受普通测距减速、障碍停车或绕行干预，设置页不再提供导航避障开启按钮。新源码说明见[导航不中途避障](导航不中途避障_20261101.md)。独立制动/避障任务保留。

本轮落实[纯惯导检查](inertial_navigation_audit_20261028.md)中发现的两项 ToF 转向干扰。该检查记录描述的是修改前的 `navigation_modes_filter_20261027`，本轮行为以此文和对应验收 JSON 为准。

设置页底部新增 **自主避障：关闭 / 开启**，上电或复位默认关闭。它与上方的“惯性导航 / 惯导加视觉”独立，两种算法都支持这个开关。设置暂存在寄存器中，不写 Flash；每次进入自主导航时锁定本次选择，退出后重新开始导航才应用新选择。

| 选项 | 自主导航行为 |
| --- | --- |
| 关闭（默认） | 按原规划路线跟踪，前方障碍只限制速度；进入停车距离后原地等待，前方清空后沿原路线继续。不会自动选择左右绕障、进入绕障阶段或改用绕障目标。 |
| 开启 | 允许按原有前方触发距离和侧方可用空间选择绕障方向，绕过障碍后回到规划路线。 |

自主导航中的“侧方距离小于 100 mm 时，用 ±3° 替换较小规划转角”在两种算法和两种避障设置下均关闭。侧方 ToF 在开启避障时仍参与选择绕障方向和绕行过程。独立的“实时避障 → 自主绕障”任务继续使用自身流程。

前方紧急停车、IMU 长时间无效、编码器异常、车轮无反馈、路线失效等原有保护继续生效。关闭避障并不屏蔽前方测距；普通障碍停车仍使用原有速度包络（默认从 650 mm 减速，160 mm 附近停止，65 mm 为紧急停车门槛）。融合模式也继续使用原有视觉有效性保护。

实现改动集中在 `vehicle_motion.v` 的两个条件：导航模式绕过侧方转角替换；自动绕障入口要求本次锁定的避障设置开启。菜单设置从 `vehicle_settings` 经 `navigation_ui`、顶层和 `vehicle_subsystem` 接入，不增加图像缓存或修改规划地图。

## 验证

- `sim/navigation_avoidance_tb.sv`：两种导航算法 × 两种避障设置 × 左右近距共 8 组，验证原先能复现的转角反向不再发生；两种算法 × 东/北两个行进方向共 4 组，验证关闭时沿原目标减速停车、静止等待、障碍清除后继续，且修改开关只在下一次导航生效。模拟停车余距为 161～164 mm。
- 同一测试另验证开启后的左右绕障方向、独立绕障任务、关闭时的紧急制动和 IMU 超时停车。
- `sim/navigation_modes_filter_tb.sv`：起步不等待视觉、纯惯导屏蔽视觉和斑马线、融合失视回退、8 次带旧计算的模式交接，以及故障停车。
- `sim/vehicle_settings_tb.sv`：新开关的默认值、点击边界、开启/关闭、跨页保持及对原算法、控制来源和速度设置的独立性；保留原菜单、触摸和手柄回归。截图由真实 RTL 渲染。
- `sim/navigation_inertial_regression_tb.sv`：重放原规划器输出的外圈左转、外圈右转、S 弯及完整照片路线，并逐次核对运动目标和路线索引。另以异常视觉、斑马线和左侧 50 mm 测距重放外圈左转，要求轨迹与正常输入逐字节一致。
- 原整车独立自行车模型回归验证开启避障时的动态障碍、回归路线与终点停车，保留编码器、传感器和阻塞故障场景；UART 协议和导航暂停/继续同时回归。

上述均为数字仿真。理想车模不能代替实车：仍需验证实际测距视场、制动距离、轮胎打滑、IMU 零偏和机械转向。尚未烧录。
