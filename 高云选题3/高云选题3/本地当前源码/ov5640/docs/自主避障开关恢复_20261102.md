# 自主避障开关恢复

入口在FPGA触摸屏：首页右上角“设置”→“自主避障”。恢复独立的“关闭”和“开启”按钮，当前选项以绿色显示。

- 上电、复位后默认关闭。
- 点击开启后，下一次启动自主导航时启用前方测距减速和绕障；绕过障碍后继续原路线。两侧均无足够空间时停车并报告受阻。
- 点击关闭后，下一次自主导航继续使用当前纯惯导路线跟踪，测距、摄像头与斑马线不会介入导航停车或纠偏。
- 导航开始时锁存选择；修改设置不会在正在执行的绕行动作中途切换算法。需要改变下一程行为时，先停下当前导航，再设置并重新启动。
- 离开设置页再返回时保留选择；该设置不修改目标速度、通信模式或手动/遥控模式。

恢复的是自主导航中的可选避障。独立“自主绕障”任务、人工停止、IMU/编码器等故障处理仍按各自逻辑工作。此修改没有恢复视觉修正或“偏离路线”自动停止。
