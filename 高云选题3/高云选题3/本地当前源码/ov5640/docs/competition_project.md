# 作品名称与简介

推荐名称：**焰巡——基于 FPGA 与边缘 AI 协同的自主消防机器人**

简短名称：**焰巡消防机器人**。

## 报名简介

本作品面向模拟道路与楼宇火情场景，设计 FPGA 与边缘 AI 协同的自主消防机器人。FPGA 接入摄像头、IMU、编码器和激光测距模块，承担实时图像处理、运动闭环、道路循迹、路径点导航及自主避障；地瓜派搭载双目摄像头与 AI 模型，识别楼宇中的火源和人员，并与下位机通过串口协同，控制云台瞄准和喷水灭火。作品探索从环境感知、自主移动到消防任务执行的协同控制方案，突出 FPGA 实时控制与边缘智能感知相结合的应用价值。

## 较短简介

面向模拟道路与楼宇火情的自主消防机器人。FPGA 完成多传感器实时处理、车辆闭环控制、视觉与惯导融合导航及自主避障；地瓜派结合双目视觉与 AI 识别火源和人员，协同云台控制与喷水灭火，探索实时控制与边缘智能相结合的消防任务执行方案。

## 参赛材料表述范围

- 对应 2026 嵌赛高云赛道选题三，重点展示 FPGA 实时感知与控制、系统稳定性、自主导航及边缘 AI 协同。
- 以上简介描述作品的系统设计。报名及答辩时，应按实际完成的联调与演示，区分单独实现的模块、通信框架和已经跑通的整机任务。
- 车型采用舵机转向，不将其写成“已实现定点原地旋转”。赛题中的这项要求应另行核对实际机械能力与参赛说明。
- 双目测距精度、灭火射程、识别准确率、导航误差、消防效果等指标，待实际测量后填写；不预先虚构数值。
- 人员识别可以辅助观察火情中的人员，不表述为已经具备人员搜救、救援或真实火场部署能力。
