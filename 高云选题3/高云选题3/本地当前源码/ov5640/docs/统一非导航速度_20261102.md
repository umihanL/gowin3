# 实时避障、遥控与手动共用速度

本次修改属于 FPGA 工程 `ov5640`。在屏幕 **设置 → 参数设置 → 速度设置** 中修改一次速度，手动触摸驾驶、PS2 遥控和实时避障共用此值。支持数字键盘输入以及 ±5、±50 调节，单位 mm/s，范围 0～1000；默认 200，断电后恢复默认值。

实时避障菜单、减速停车页和绕障页的右上角也增加“速度设置”。任务页显示当前目标速度。运行中点击设置会先离开运动页面、停止当前任务；修改后需要重新选择任务启动，不会自动继续旧动作。

## 各模式怎样使用速度

| 模式 | 速度行为 |
| --- | --- |
| 手动触摸驾驶 | 前进为设定值，后退为其负值；停止保持为 0 |
| PS2 遥控 | START 巡航使用设定值，摇杆按推杆比例映射到正负设定值；原 R1/R2 调节也更新同一个值 |
| 实时避障 → 减速停车 | 使用共享速度作为起始目标；按距离逐步减速，原独立“减速初始速度”参数已合并 |
| 实时避障 → 绕障 | 障碍物较远时使用共享速度，不再固定封顶 200；进入绕行最多 80，绕行及结束段最多 100，并且始终不超过共享速度 |
| 本地地图导航 | 使用独立的原巡航上限 200，弯速仍为 120/140；共享速度设为 0 或更改其他值不会改动导航速度 |
| X5 下发的地图导航 | 继续使用原 UART 导航速度及导航阶段限速，不受共享设置影响 |

例如设为 **150 mm/s（15 cm/s）**：触摸前进和遥控巡航目标都是 150；避障直行目标也是 150，靠近障碍物后减速。设为 50 时，绕行不会被旧代码中的固定 80/100 提高速度。设为 0 时，手动、遥控和实时避障均不产生前进目标。

这里统一的是目标速度，实际车速仍受编码器闭环、加减速、转弯差速与测距减速影响。最大可输入值不是实车已验证的稳定速度。X5 的独立距离移动/语音移动协议参数不属于 FPGA 屏幕的“手动模式”，本次未更改该协议。

独立绕障在输出目标速度超过原 200 mm/s 巡航范围时采用较快的降速步长，以便及时进入低速绕行；速度回到 200 以内后恢复原细步长。该调整仅作用于实时绕障，导航速度控制没有使用这项新斜率。长距离绕障用例的新旧斜率均通过，初次测试失败来自旧测距夹具，不能据此宣称实车绕障精度已提高。

## 参数页变化

参数页现在只有四行：速度设置、减速起始距离、绕障触发距离、舵机中位。删除了重复的独立减速初速度项，原距离参数和舵机调节仍保留。

## 本地验收和编译

- 设置/触摸/PS2 联动回归，包括输入边界、断链停车、设置切换和新页面入口。
- 实时避障独立轮速/IMU 仿真：0、50、350、1000 四组巡航目标，低速绕行不超设定值，400 mm/s 原距离停车回归。
- 子系统速度接线回归：32 组模式、来源与速度组合，检查导航隔离以及选择通信来源后不会覆盖独立避障的速度。
- 200/1000 mm/s 长距离接近实际障碍的完整绕障仿真，包含独立测距射线、车身碰撞检测及回到原直线；该新增测试按当前测距驱动采用 4 m 量程，并先生成有效首帧，避免旧夹具的占位距离造成虚假障碍。
- RTL 像素渲染检查参数页、共享速度页和避障页。

测试记录目录：`diagnostics/shared_speed_20261102/`。完整编译生成的正式下载文件为 `impl/pnr/ov5640.fs`，对应来源和校验值见 `impl/pnr/ov5640_current_audit.json`。本轮仅本地修改、仿真及编译，不烧录、不连接小车；按照既有要求不另做时序验收。

相关代码：`src/navigation/vehicle_settings.v` 管理唯一速度寄存器；`nav_control.v` 和 `nav_renderer.v` 提供入口及显示；`src/vehicle/vehicle_subsystem.v` 隔离导航速度来源；`vehicle_motion.v` 将共享速度用于独立避障并保留阶段减速。
