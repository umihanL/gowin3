# 逆透视标定需要提供的资料

先把相机固定到最终位置、固定焦距/对焦和图像模式，再测量。35° 可作为你准备尝试的安装角，但必须以实拍确认近处道路与弯道出口的可见范围；增加俯角并不能保证整段弯道可见。逆透视只变换已有图像，无法补出画面外的道路。

## 1. 相机图像和模式（必需）

- 完整原始相机图像，注明分辨率（当前工程正常视频为 640×480）、是否镜像/旋转、是否裁切或数字缩放。不要用扫描软件美化、透视矫正或裁剪。
- 若只能拍屏，提供正对屏幕、包含相机有效显示区域四角的完整照片；标明实际相机图像区域。直接原始帧更准确。
- 整个测量过程车和相机都不移动，保持焦距、对焦、分辨率、裁切设置一致。

## 2. 地面坐标与像素对应（推荐的直接标定资料，必需）

原点取车头中点的地面投影；X 向车前为正、Y 向车左为正，单位 mm。图像左上角为 (u=0,v=0)，u 向右、v 向下，使用原始相机图像坐标。

提供 `(X_mm, Y_mm, u_px, v_px)`。至少 4 个不共线且分布良好的点，建议 9～12 个，覆盖将用于循迹的近、中、远、左、右区域，不能只给画面两个角的地面距离。

可先在车头前 **15、25、40、60 cm** 四个距离处，每处放中心线及左右 **10 cm** 标记，构成最多 12 点；只取实际可见的点，不可见就调整距离。既不要求这些距离必须全部入镜，也不要为凑数估计看不见的点。至少覆盖三个不同远近层次和左右宽度。

如果不会读取像素，可提供能看清编号标记的原始图像及每个编号的地面 (X,Y)，后续从图像提取对应像素；拍屏时必须保留四角以先校正拍摄透视。还应留出几个不参与拟合的实测点，用来检查误差。

## 3. 安装几何（同时记录，用于校验和备用模型）

- 光心到地面的垂直高度 H。
- 光心地面投影相对车头中点的前后位置 Xc、左右位置 Yc。车头后方为负 X，车左为正 Y。
- 最终光轴俯角：水平为 0°、垂直看地为 90°；如果调整到 35°，填写调整后的实测值。另记左右偏航角、画面横滚角，无法精确测量就明确写“估计”。
- 画面中心 (u=W/2,v=H/2) 对应地面点距车头多少、偏左或偏右多少；这是交叉校验项，不能单独求出完整逆透视。

有足够准确的平面点对应时，可以直接拟合地面单应矩阵，不必强依赖手量的精确俯角或焦距。几何资料仍可用于检查点位、坐标方向和拟合结果，不能把“有几何信息”当作无需标定。

## 4. 镜头内参与畸变（提高精度，推荐提供）

优先提供当前模式下标定得到的 `fx, fy, cx, cy`、畸变系数 `k1,k2,p1,p2,k3` 及模型类型、对应图像分辨率。这里 fx/fy 是像素焦距，不是只报镜头标称几毫米。鱼眼镜头要注明鱼眼模型，不能直接套普通畸变系数。

没有内参也不用自己猜：拍约 15～20 张清晰棋盘格原始图像，棋盘覆盖画面中央、四周并有不同倾斜姿态，提供棋盘内角点行列数、每个方格实际边长。可据此求内参与畸变。相机固定、移动棋盘即可。

只靠几个地面点直接做单应映射适合畸变较小或局部区域；明显镜头畸变需要先校正再做逆透视，增加地面点不能让一张单应矩阵完全消除镜头畸变。

## 5. 道路及验证资料

当前道路实测为外圈路宽 **373 mm**、内圈及S弯 **340 mm**；车宽200 mm、轴距142 mm、已测舵机40～150。确认道路是否沿两侧对称加宽、中心线是否保持原位；若中心线移动，需要提供新中心线尺寸。硬件结构没有改变就不必重复测量。另建议测道路**中心线**弯曲半径，并拍居中、左右偏30 mm、左右偏航约5°的验证图，注明实际状态。更换相机高度后，旧投影表必须重新标定；逆透视测量地面点距离，多帧对应或已知地标才能进一步估计车辆行驶路程。

最少先交付：固定相机的完整原图、图像模式、9～12 个地面标记的实测坐标及对应像素（或清晰编号原图）。安装几何一并记录；若要减少画面边缘误差，再提供棋盘格标定资料。
