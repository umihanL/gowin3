# 斑马线减速与 S 弯换向改进（2026-10-29）

自主导航仍由 IMU 航向、编码器里程和规划中心线驱动。视觉不参与位置校准、路线选择或转向，只输出斑马线检测结果给限速逻辑。本轮位流已完成综合、布局布线和时序检查，尚未烧录、尚未实车验证。

## 斑马线减速

旧检测器只检查上下交替的横带，并要求画面底部出现白带；赛道图中的斑马线白条沿道路方向排列，因此容易漏检。新检测器同时检查两种方向：三个独立纵向窗口至少两个匹配横带，横向扫描则要求多行重复的白条和暗间隔。检测区域为缩略图第 24 至 74 行，允许条纹倾斜、偏移和少量噪点，并拒绝单线、两条道路边界、孤立噪点和过短纹理。

检测使用 RGB565 亮度和独立的逐帧亮度阈值，不受二值化预览滑块设为 0 或 255 的影响。完整帧确认斑马线后，速度目标变为 `min(正常限速/2, 60 mm/s)`：正常目标 200 mm/s 时降到 60 mm/s，80 mm/s 时降到 40 mm/s。限速每 10 ms 下降 4 mm/s；连续有效画面确认斑马线消失后每 10 ms 恢复 2 mm/s。自主导航底栏显示红色 `ZEBRA 0060 mm/s`，数字是当前速度指令。无效帧保持上一次状态，不会因单帧抖动立即恢复。

## S 弯换向

S 弯原本由两段相切反向圆弧组成，几何、半径、端点和跟踪器均保持不变；仅将 S 弯中心线采样间距从约 45 mm 加密到约 10 mm。节点数从 1632 增加到 1764，仍使用 11 位索引和原有 RAM 容量。规划器正向和反向输出均为 125 点，显示点与执行 RAM 逐点一致。

独立后轴自行车模型回放显示，换向局部最大横向误差由 10.19 mm 降至 7.57 mm，相邻 20 ms 转向指令最大跳变由 4° 降至 2°，转向接近零的时间由 280 ms 降至 220 ms；反向 S 弯局部误差为 5.27 mm。整条正向 S 路线峰值为 17.63 mm，原版 17.62 mm，说明本次改善集中在换向瞬间，不能代表全路线误差下降。该回放不包含轮胎打滑、舵机回差和实车地图比例误差。

## 验证

- `sim/vision_zebra_tb.sv`：横带、纵向条纹、倾斜、偏移、噪点、无效帧保持和清除，以及误检拒绝。
- `sim/vision_zebra_exposure_tb.sv`：暗/亮场景自适应阈值和预览滑块边界值。
- `sim/inertial_zebra_camera_tb.sv`：斑马线检测、200→60→200、80→40、暂停、模式切换、急停，以及视觉不改变路线和转向。
- `sim/vehicle_overlay_tb.sv`：`ZEBRA` 和速度数字显示、清除和模式隔离。
- `sim/run_zebra_smooth_routes.py`：双向 S 弯、外圈左右转、照片路线的实际规划和闭环运动回放。
- 综合后抽取的 `vision_zebra` 网表仿真：`sim/zebra_smooth_detector_netlist.log`，结果通过。

综合网表与 RTL 逐周期比较了 105,482 个时钟周期；该检查只覆盖检测模块，完整曝光算术由单独的 RTL 光照测试覆盖。

`tools/densify_s_bend.py` 只对已接受地图的 S 弯重采样。全图生成器原有一处路口几何预检要求约 32.35° 转角，而标定检查上限为 28°，因此本次没有运行全图重建，也没有放宽检查或修改其他路口。完整重建仍需先解决这一既存约束。

旧测试 `sim/nav_ui_tb.v` 引用已不存在的 `dut.control.planner.state`，无法展开，不计为本轮通过项目。实际 UI 模块编译和显示覆盖层测试已通过。
