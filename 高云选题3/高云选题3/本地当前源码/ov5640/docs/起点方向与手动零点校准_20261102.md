# 起点方向与手动零点校准

IMU 上的 0° 是本次摆车后的相对零位，地图上的 0° 是向右，两者不是同一个坐标基准。车头朝地图左侧时，即使刚按零点校准、IMU 显示 0°，地图箭头仍应设为 180°。

导航使用：**当前地图航向 = 确认的地图航向 + IMU 相对该参考时刻的转角**，并在 ±180° 边界归一化。人工起点和方向的确认不要求车辆先物理转到 0°。

## 本次修复

原版已有上述差分换算，但顶层没有把人工零点按键事件通知导航和运动控制。地图方向先确认、之后再按零点时，导航可能继续减去旧 IMU 角度；运动控制也可能保留清零前的待处理角度样本。

旧版仿真已复现：确认地图朝向 90° 时，IMU 原始值为 37.5°；车身不动再次清零后，地图航向错误跳成 52.5°。这会产生并不存在的 37.5° 航向误差。修复后同一用例保持地图 90°。

现在将人工清零事件独立传入两处：

- 原地、非运行状态下清零，暂存已有地图朝向，等待校准失效、完成，再以新 IMU 角度重新建立参考。不会把地图方向变成 0°。
- 校准未完成时不允许导航起步，不采用缺失参考时默认 0° 的启动路径。
- 运动控制丢弃旧零点的待处理角度，要求新鲜有效样本后才使用新基准。
- 行驶或规划期间清零会撤销当前路线/方向参考；行驶中的自动控制停止，不能继续沿着被重新命名的角度行驶。意外传感器重启也不会被当作原地人工清零。

## 推荐操作

1. 把车放到真实起点，静止按零点校准。
2. 等 IMU 校准完成。相对角度显示 0° 正常。
3. 在地图确认真实位置和车头朝向：右 0°、上 90°、左 180°、下 −90°。弯道可用实际斜角。
4. 规划并启动导航。无需为了迎合 IMU 的 0° 把地图箭头也设成 0°。

若先确认地图方向、再在原地按零点，新程序会在校准完成后衔接参考。校准期间保持车身静止；搬车或转动车身后应重新确认实际起点与地图方向。
