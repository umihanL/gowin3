实际满舵左转 36°、右转 34°。规划取较小的 34°限制两侧，`138/tan(34°)=204.6 mm`，最小半径向上取 205 mm。遥控/触摸可用各自实测端点，内轮保持同方向。

`VEHICLE_SERVO_SIGN=1` 将左转正角映射到舵机角增大，修正用户反馈的左右相反。转角每 10 ms 变化最多 1°，差速与舵机使用同一平滑转角。用户已确认 M1 左后轮、M2 右后轮；M2 引脚交换及编码器方向保留前版修正。

## 导航计算

地图点选和显示位置参考点是车头中点，地图原点在左下，X 向右、Y 向上，内部位置为 mm Q8。初始化从车头减去 228 mm 航向偏置得到后轴，后轴积分后再换算车头。每次启动重新记录两编码器和 IMU 基准，导航相对计数从零开始；电机测速仍使用原始连续计数。

后轴路程由编码器计算：`distance = mean(delta_left,delta_right) × pi × 66 / 1560`。编码器左右轮差除以后轮距 168 mm 预测航向，IMU 相对偏航渐进校正，再用 sin/cos 积分；不对加速度二次积分。小车车头须放在所选起点，并沿首段切线摆正。当前没有地图绝对定位，无法仅凭静止 IMU 获得地图绝对朝向。

规划成功后，`vehicle_route_profile` 顺序读取路径 RAM，按中间点分为最多 9 段，估算路程、航向、前轮转角和左右轮圈数。该历史预览按路径弧长近似轮轴弧长，改为车头参考后，曲线段圈数及转角仅供粗略预览，不作为执行指令。实际导航使用车头偏置追踪及两轮编码器/IMU 闭环，差速由当前转角计算；未把粗估圈数用作开环终止条件。

车头追踪采用 `delta=atan2(2*138*lateral_error, lookahead_distance²+2*228*max(forward,0))`，前视 140 mm，分母下限 100 mm 的平方，横向 ±2 mm 死区。相邻触点的细小横/竖偏差会对齐，中间点通过容差约 60 mm，终点约 18 mm。小角度跟踪仅单侧距离小于 100 mm 时附加 3° 避让。转弯限速，终点前逐步降速。后轮外轮不超过请求速度，内轮按 `(R-track/2)/(R+track/2)` 缩放，各自使用 10 ms 编码器 PI 闭环。

航位推算会受打滑、轮径误差、IMU 漂移影响。地图由图片提取，静态车体筛查通过不能替代实物地图和车体尺寸标定；目前没有绝对定位校正、倒车搜索或舵机角度反馈。

## 停车与绕障参数

界面可设减速起始距离 25～200 cm、减速初始速度 80～400 mm/s、绕障触发距离 35～150 cm。停车采用 85 mm 基线、约 200 ms 行程预留的平方根包络，每 10 ms 最多降速 40 mm/s，叠加 TB6612 短路制动与编码器静止确认。正常加速和其他模式每次最多变化 2 mm/s。单纯丢回波继续使用距离记忆和里程计。参数、制动模型和实车限制见 [自动运动说明](auto_motion.md)。

绕障比较两侧空间，侧方起步下限 250 mm，相同时选右；单前束近物优先向另一可用侧绕。选定方向后不因外侧 40～50 cm 正常读数改判两侧不通。目标偏航约 40°，前束按距两侧边界各内缩 30 mm 建模，两束越过边缘后再行驶约 60 mm 且横向偏移至少 160 mm 才回正。平行阶段侧方目标间距 35～75 mm，绕行上限 100 mm/s。侧传感器确认障碍尾端后继续 250 mm 再回原线，覆盖 300−80=220 mm 车尾长度并留 30 mm 余量。独立绕障回线后继续约 400 mm 停车；导航绕障恢复原路线和原终点。侧向尾端不能确认或超过约 3 m/60 s 则停车。四束测距不能重建任意障碍轮廓或保证复杂未知环境通行。当前制动包络及各项限制见 [自动运动说明](auto_motion.md)。

前束数据超时默认 800 ms，IMU 更新超时 1.5 秒；任一车轮持续无计数默认 1.5 秒报故障。IMU 需先完成静止校零，短时掉帧用编码器差分预测航向、保留零参考。连续 SPI 全 1 局部重读，FIFO 溢出只清 FIFO；真正融合重启或 S0 才重新校零。持续无有效姿态仍停车。

## 引脚

原摄像头、TFT、DDR、触摸、IMU 引脚保留。新增引脚来自 MOTOR 现有约束和用户引脚表，统一写在 `src/ov5640_ddr3_tft.cst`。

| 信号 | FPGA 引脚 |
| --- | --- |
| dir[0] / dir[1] / pwm_out | B18 / D16 / C19 |
| encoder_A / encoder_B | F20 / E18 |
| dir2[0] / dir2[1] / pwm_out2 | C17 / B16 / C15 |
| encoder2_A / encoder2_B | F19 / F18 |
| PS2 CS / MOSI / CLK / MISO | A18 / A15 / F13 / A13 |
| 舵机 PWM | D19 |
| VL53L0X SDA / SCL | B17 / C18 |
| XSHUT1 左侧 / XSHUT2 左前 | C14 / B15 |
| XSHUT3 右前 / XSHUT4 右侧 | D17 / E16 |
| UART TX | M15 |

上面三行 ToF 引脚已按当前 CST 和最终 P&R 引脚报告纠正：旧说明曾将 SDA/SCL 及 XSHUT 顺序写反。以当前 `src/ov5640_ddr3_tft.cst` 为准；本次纠正文档未修改 RTL、CST 或下载位流。

GPIO 电平沿用 LVCMOS33。I2C 复用原开漏驱动；外设与 FPGA 共地。保留原 MOTOR 电机供电、STBY 和编码器电平连接方式。

## 构建与验证

新增硬件统一运行在现有 33 MHz 显示时钟，全部时间参数按该时钟配置；电机原固定 2000 周期 PWM 为 16.5 kHz，舵机为 50 Hz。UART 由独立的 `imu_firewater_tx.v` 驱动，为 115200 / 8N1，每 50 ms 发送七通道 FireWater 帧 `samples:Roll,Pitch,Yaw,target1,actual1,target2,actual2`；角度为度、一位小数，速度为 mm/s、有符号整数，帧尾为 CRLF。IMU 无效时前三路填 0，电机数据继续发送。屏幕继续使用 RotXYZ，导航航向仍接收原 `imu_yaw`，不使用 RotZ。VOFA 欧拉控件绑定索引 0/1/2，速度绑定 3/4/5/6（从 0 开始）。舵机输出范围现为 20°～160°、中位 90°；M2 驱动命令和反馈符号已在软件中反转，接线不改。详见 [本次修改](settings_and_drive.md)。现有 Gowin DDR/FIFO IP 保留，没有额外 DDR 或未经配置的新 IP 依赖。PI 的四拍多周期约束沿用原 MOTOR 的输入捕获/延迟使能关系，其余控制路径正常计时。

为满足器件 118 块 BSRAM 上限，动态目标速度转换改用逐拍移位累加，PS2 轴映射和差速使用逻辑查表，未新增 FIFO 或 DSP IP。舵机脉宽表及测距限速表保留。`motor_import.diff` 是最初导入的历史差异；最新范围见本版审计。
