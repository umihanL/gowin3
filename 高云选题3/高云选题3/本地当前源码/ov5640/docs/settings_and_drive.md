# 设置、调速与转向差速

本版下载文件仍是 `impl/pnr/ov5640.fs`。引脚约束、IMU、摄像头、DDR 和七路 FireWater 格式保持原配置。

## 使用方法

每次上电或整机复位：**手动模式、目标速度 200 mm/s、电机停止**。设置保存在运行寄存器中，断电不保留。

主菜单右上角新增“设置”：

- **模式选择**：手动模式仅允许触摸驾驶；遥控模式允许 PS2 驾驶。切换模式需经过设置页面，原驾驶状态会停止，返回后重新启动。
- **参数设置 → 键盘输入**：数字 0～9、删除、确认。允许 **0～1000 mm/s**；超限输入被拒绝并显示提示。只有确认后才更新目标。
- **参数设置 → 按键调节**：`−50、−5、+5、+50`，点击立即保存，上下限饱和。

返回主菜单的“遥控模式”入口进入驾驶页面。手动模式下显示触摸驾驶按键：前进、后退、左转、右转、回正、停止。前进/后退是点击后保持运行，左右转向保持所选角度；点击停止或退出页面会停车。再次进入不会恢复上一次运行状态。此页的目标速度与设置页始终一致。

遥控模式下，START 启停，右摇杆上下控制速度，左摇杆左右转向，SELECT 锁定/解锁转向。**红色圆圈键**进入速度设置，再按一次退出；设置中 **R1 +50、R2 −50**，按住不重复触发。进入设置会停车，退出后需重新按 START。断链停车，重新连接或进入页面时，按住 START 不会自动启动。

触摸和手柄始终修改同一个目标寄存器。手动模式屏蔽所有 PS2 驾驶、调速事件；遥控模式中的触摸驾驶按键不生效，设置页面仍可调整共享参数。

0～1000 是手动/遥控的可设目标上限，并非电机必然能达到的实测速率。自动减速停车、绕障与地图导航保留原来的最高 200 mm/s 及原来的减速保护；本次共享设置用于手动和遥控驾驶。

## 响应速度

原目标转换只有 256 项 ROM，并且限制在 200 mm/s。本版改为逐拍常数乘法，支持完整 ±1000 mm/s，不新增 BSRAM 或 DSP，速度与编码器目标成对提交。

两轮仍各自使用 10 ms 编码器 PI。调整为：启动/目标明显变化时较快积分、接近目标后较低积分、过速时较快卸载积分；目标改变后重新进入快速阶段。保留输出饱和、积分抗饱和、停止清积分和换向空白时间。比例测量窗口从 40 ms 改为 20 ms，串口实测速度窗口从 80 ms 改为 40 ms。

这是基于目标变化的**分段增益切换**，没有进行电机参数自动辨识，也没有宣称 PID 自整定。仿真使用独立摩擦/惯性模型与改动前原 PI 对比；模型响应改善不能代替实车、电池电压和负载下的阶跃测量。

## 几何和转向

| 参数 | 本版值 |
| --- | --- |
| M1 / M2 | 左后轮 / 右后轮 |
| 前后轴距 | 138 mm |
| 后轮中心距 / 前轮中心距 | 168 / 175 mm |
| 轮径 / 每圈编码器计数 | 66 mm / 1560，计数沿用原值 |
| 左转 / 右转最大等效前轮角 | 36° / 34° |
| 舵机中位 / 限位 | 90° / 20°～160° |
| 规划角度 / 最小后轴中心半径 | 两侧保守用 34° / 205 mm |

修正后的左转使舵机角增大，右转使舵机角减小。舵机 160°对应左转 36°，20°对应右转 34°。中间点先按线性连杆比例估算，后续可根据实测角度更新 `servo_offset.mem`；M2 驱动与编码器方向保留上一版的修正。

转角每 10 ms 最多变化 1°等效前轮角。后轮差速和舵机映射使用同一个平滑转角：

```text
R = 138 / tan(|转角|)
内轮目标 = 外轮目标 × (R − 84) / (R + 84)
```

外轮不超过设定速度；左转 M1 较慢，右转 M2 较慢，倒车也保持同样的轮速绝对值比例。200 mm/s 满舵时，左转内轮约 77 mm/s、右转内轮约 84 mm/s。两边各自闭环跟踪目标，七路串口可观察真实下发的两路目标及反馈。

前轮距用于机械标定说明。后轮差速由轴距、后轮距和等效前轮角决定；只有一个舵机、没有转向角反馈，软件无法分别控制两个前轮的阿克曼角。需要更精确时，应测量左右转的若干中间舵机位置对应的两个前轮角或实测圆周半径。端点尺寸、轮胎接地和连杆几何不足以保证所有地面、速度下完全不打滑。

地图占据栅格不变；尺寸元数据、编码器里程、路线圈数、跟踪器和差速表使用新尺寸。规划半径从 120 改为 205 mm，平滑次数增为 512，无法满足新曲率条件的路线继续拒绝执行。
