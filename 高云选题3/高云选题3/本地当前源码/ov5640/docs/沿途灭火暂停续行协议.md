# 编号路线沿途灭火：复用现有暂停、续行协议

本功能不要求改 FPGA RTL。现有 `05` 暂停与 `07` 续行已保持导航路线、里程计位置、转弯状态和任务号。新增的沿途火焰巡检、自动灭火轮次和恢复行驶后 3 秒火焰停车抑制由 X5 执行。

## 指令与回读

| 操作 | CMD | D0～D3 | 必须观察的后续状态 |
|---|---|---|---|
| 暂停原编号路线 | `05` | 全 0 | 同一任务号、nav_session=true、run=false；还需 EXT_STATUS 的实测停稳标志 |
| 水枪关闭并清锁 | `19` | 全 0 | `1A` 新鲜回读明确 B13 为低；开始喷水前还要求 ready、停稳与其他云台条件 |
| 有限喷水 | `18` | D0/D1=毫秒数，D2/D3=0 | 最大 1000 ms；不能靠心跳或重发延长一轮喷水 |
| 继续原路线 | `07` | 全 0 | 同一任务号、nav_session=true、run=true；不得重新发送 START/SET_START 冒充续行 |

`87` 续行 ACK 为 `D0=result、D1=flags、D2/D3=速度上限`，没有任务号。X5 必须继续查询 `01` 心跳或 `06` 状态，用查询发送时间/序号排除旧包，并核对任务号。ACK 仅表示接收，不代表车轮已经运动。

暂停时 `motion_status` 通常仍为 2（原导航正在执行），而 `run=false` 表示已暂停；不能把状态 2 单独解释为“车正在动”。车轮是否停稳须读取实际速度判据。暂停不清空里程计，也不把位置重新设到起点。

## 水枪与续行顺序

STOP 会立即关水，并将水枪 lockout 置位；停稳后仍需显式 `PUMP_OFF=19` 才能清锁。自动瞄准与喷水继续经过原有云台标定、目标、角度反馈及 B13 门控。

只要 B13 为高，`07` 返回 BUSY=4，不续行。明确关水并收到新鲜低电平回读后，再请求续行。恢复路线时，FPGA 也会再次撤销水枪输出。不得在收到 `18` ACK 后就宣称灭火完成；自动轮次还要观察真实有限输出与关闭反馈。

离开通信/导航页面或控制模式会撤销会话；此后 `07` 不能恢复。心跳失联会停车，恢复心跳本身不会启动车辆。X5 应将这类中断视为任务故障或人工取消，不自动恢复喷水/行驶。

## 软件接口约束

X5 原 `NumberedNavigation.cancel()` 是终止语义，不能复用为沿途灭火暂停。沿途灭火应有独立的暂停确认、停稳灭火、关水确认、续行确认及冷却阶段；保持同一个编号导航 task_id、目标点和原路线。3 秒抑制仅影响火焰引起的停车触发，YOLO 画面和其他目标检测可以保持运行。
