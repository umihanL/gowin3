02 · 实际零点、方向与限位

几何角 =（执行器角 − zero_angle_deg）× positive_direction。几何 pan 正方向绕 +z（朝左）；几何 tilt 正方向绕 −y（抬高）。每次启动参考改变后需重新核验绑定。

上电后按这个顺序实测

  1. 先保持泵输出关闭，尺量相机、两转轴与喷嘴出口的位置和方向，填写安装记录；实测零点、方向及限位，核对实际参考ID。
  2. 辨认物理左右眼和图像旋转，确认同步曝光；拍摄至少20组有效同步棋盘格（建议30～50组），记录实际格长及独立测试距离。
  3. 用 tools/calibrate_stereo.py 标定并检查留出重投影；再对独立尺量距离验收米制深度，填写对应来源帧与图像尺寸。
  4. 在无水输出条件下验收几何瞄准、真实反馈时延、角度精度、2mm射线门槛与机械可达范围；预设或保持同一开机姿态不能替代验收。
  5. 具备实测条件后，在固定安装和固定泵设置下采集完整水流网格，每单元采独立内部验证点。填落点误差和编码器误差，保留原始证据。
  6. 下载草稿交给现有后端校验流程审阅；本页不会把填写完整等同于标定通过。任何配置、安装或启动参考变化都需重核绑定。
