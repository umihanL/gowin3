# 固定相机云台标定操作

适用结构：相机固定在车身上，水平/俯仰云台只带喷嘴。当前采用用户确认的安装尺寸、无俯仰/侧倾方向和直线瞄准策略；双目控制精度与轴参考绑定仍待验收。标定草稿页面用于整理参数，手动B13试喷在实车控制台独立提供。

## 手动B13试喷

上位机“视觉与瞄准 → 手动试喷”选择100～1000毫秒后点单次试喷即可，无需额外勾选，也不要求火焰目标或双目标定。未就绪时点击会说明未发送的具体原因，立即关水独立可用。当前FPGA固件要求处于上位机控制页；首页进入“拓展2对话控制”即可，不需要启动行驶。修复后的X5程序将页面未授权与UART断线分开，不会因控制页外STOP被拒而反复断连。

## 厂家参数接入

`config/stereo.factory.json`保存EEPROM转换后的米制双目参数；`config/gs130w_intrinsics.factory-mapped.json`将EEPROM第0组配到`/image_right_raw`、第1组配到`/image_left_raw`，与实机对照结果对应。原始快照保留。

`config/stereo_runtime.factory.json`启用观测测距。上位机“视觉与瞄准 → 双目测距”独立显示画面中心100×100区域的距离；即使同时检出火源，中心探针也保留，并明确标注“非火源”。火焰估距按采集帧和检测框展示，不冒用更新后的火焰编号。界面同时显示采集年龄，超过3秒的历史观测清空。观测值不会被当成已验证的自动瞄准或喷水距离。

测距保留1280×1088原像素，按目标区域附加视差搜索及匹配边界后计算，未降低YOLO输入、预览分辨率或JPEG质量。主眼必须精确对应检测帧，右眼需在允许时间差内唯一匹配；原0.5秒控制数据期限及深度质量门限保留。仅用于标定显示的观测允许计算完成时距离采集不超过1.5秒，超过0.5秒明确标为“延迟观测”，保留原采集时间且不发布控制深度。2026-11-03板端实拍单独诊断中，原整图计算约5.18秒，中心区域约133毫秒，纸箱区域约75毫秒（含整流和采样）。全部服务并发时耗时会增加，不能把单独诊断耗时等同于上位机端到端延迟。

用户确认“Mini PC”纸箱正面尺量为1.72米。该实拍帧厂家参数估计的相机前向Z为1.78065米、到框中心的斜距为1.80013米，分别相差约6.1和8.0厘米。局部计算与同帧整图的纸箱读数基本一致，不能据此消除实际尺量误差。这是单距离核对记录，尚不代表多距离精度或喷水命中验收；未用1.72米强制缩放输出。纸箱在画面稍上方，中心探针落在下方桌架，二者不可混为同一测量。

启动脚本会优先选择各自的`.local.json`，没有时选择上述厂家配置，再没有时才使用模板。视觉和任务节点使用同一镜头映射，避免YOLO画面与三维坐标的校正参数不一致。

手动试喷不依赖以上标定。FPGA回包里的HIGH/LOW是输出寄存器状态，不是针脚电压或水流测量。如果已收到开启和关闭回包而水泵完全不动作，应单独排查B13到MOS栅极的输出链路，不能通过填写标定参数解决。

用户最新表格替换此前尺寸。相机与喷嘴初始仍朝车身左侧。原点采用本次测量的**水平轴参考点P**；俯仰轴参考点T在P上方30mm，不能继续令P=T。原始尺寸按车体系 x车前/y车左/z向上：

| 测量关系 | 原始车体系 [x,y,z]，mm | 程序云台基系 [x,y,z]，m |
|---|---|---|
| 相机 C 相对 P | [-95,130,0] | [0.130,0.095,0] |

从实车控制台进入“固定相机标定”，或直接打开 `web/fire_commissioning.html`。页面和同目录 `fire_commissioning.js`、`fire_commissioning.css` 即可离线使用。外链CSS适配服务端现有CSP，不需要放宽策略。页面没有网络请求、电机接口、水泵接口或配置提交接口。

4. “下载完整草稿”导出 `fire_commissioning.draft.json`；关闭或刷新前需下载备份。
5. “导入草稿 / 标定资料 JSON”支持完整草稿及现有四种配置。导入文件大小限制2MB。页面复制参数供整理，原文件不变。

## 预设与坐标符号

云台基坐标为 x前/y左/z上；相机光学坐标为 x右/y下/z前。转换式：

```text
p_gimbal = R_camera_to_gimbal * p_camera + t_camera_origin_in_gimbal_m
R（假设相机与车身正向对齐）= [[0,0,1],[-1,0,0],[0,-1,0]]
```

“喷嘴轴心在相机后方5cm、下方8cm”在假设云台原点与喷嘴轴心重合时，表示相机在云台原点的前方5cm、上方8cm，因此 `t_camera_origin_in_gimbal_m=[0.05,0,0.08]`。不能把“喷嘴相对相机”的负向位移直接填到“相机相对云台”字段。

预设中水平工作范围−90°～90°、俯仰0°～60°来自用户确认；实际执行器限位仍需核对。其余均是假设：两轴及喷嘴出口原点重合、喷嘴沿+x、执行器零点0°及方向+1、单眼1280×1088、演示距离0.2～2m。这些假设会写入草稿的 `assumptions` 与测量记录。预设不生成双目矩阵或水流样本。

实际安装必须分开测量：

| 字段 | 应测量的量 |
|---|---|
| R_camera_to_gimbal | 光学系到云台基系旋转，正交且行列式+1 |
| t_camera_origin_in_gimbal_m | 相机光学原点在云台基系中的位置 |
| tilt_origin_in_pan_m | 几何零位时，俯仰转轴原点在水平转轴系中的位置 |
| nozzle_origin_in_tilt_m | 喷嘴出口在俯仰轴系中的位置 |
| nozzle_direction_in_tilt | 喷嘴在俯仰轴系中的单位方向向量 |

辅助安装角采用 `Rz(yaw)·Ry(pitch)·Rx(roll)·R_optical`，依次绕固定基坐标x、y、z旋转。它不是任意欧拉角软件的通用默认约定。也可直接录入实际测得的3×3矩阵。

## 实际零位与编码器参考

```text
几何角 = (执行器角 - zero_angle_deg) * positive_direction
pan 正方向：绕 +z 朝左；tilt 正方向：绕 -y 抬高
```

记录几何零位时的实际执行器读数，实测执行器读数增大时的物理运动方向，再填正负号。限位字段是执行器坐标中的范围，应与实际执行器状态完全一致。不要仅凭串口计数正负推断喷嘴朝向。

现有 `tools/capture_mixed_reference.py` 涉及板端串口读取，带 `--apply` 会写入实际启动参考配置；本页面不会调用它。X5关机时不执行。上电后按其现有工作流建立参考，再记录实际 `reference_id`。每次capture都会生成新ID，旧几何与落点绑定必须重新验证。同一开机姿态不能替代参考ID、精度或安装验收。

## 双目采集与工具

实测物理左右眼、原始图像旋转、同步曝光以及棋盘格格长。采集至少20组有效同步棋盘格，建议30～50组，覆盖图像和工作距离。另保留独立尺量距离用于深度尺度验证。文件名或时间戳接近不能单独证明同步曝光。

现有命令格式如下，其中路径、内角点列/行数和格长必须替换成实际采集值；只有确认同步曝光后才可使用确认参数：

```text
python tools/calibrate_stereo.py --left <左眼目录> --right <右眼目录> --cols <实际内角点列数> --rows <实际内角点行数> --square-m <实测格长米> --output <报告目录/stereo.measured.json> --synchronized-capture-confirmed
```

该工具按每5组留出1组独立验证，检查重投影、极线误差与覆盖范围。导入其结果后保留原报告，另外记录尺度验收证据。页面不会将工具质量通过替代 `physical_eye_mapping_verified`、`synchronization_verified` 或 `metric_depth_verified`。来源帧、单眼尺寸、标定ID须与实际深度输出一致。

## 水流落点记录（仅实测补偿策略需要）

测水路和收集落点时，可在实车控制台“视觉与瞄准 → 手动试喷”按当前喷嘴方向输出一次 0.1～1 秒脉冲，默认 0.4 秒。该入口不依赖已完成的水流标定，也不会自动转动喷嘴。等待真实关水反馈后再调整位置；无需把草稿的 calibrated/verified 改为 true 来获得试喷权限。

按 `docs/固定相机实测落点接口.md` 采集名义水平角×名义俯仰角×喷嘴前向距离的完整角点组合，每维至少2个值。最小2×2×2网格为8个角点；每个网格单元还需要独立、严格内部的水流验证点。

角点记录包含 `angle_correction_deg=[水平修正,俯仰修正]`；独立验证记录改为实际 `commanded_angles_deg`。二者都必须记录 `measured_impact_error_m=[x,y,z]` 及 `measured_encoder_error_deg=[pan,tilt]`，ID不得重复。页面允许增删改，不把缺失误差补零。

距离必须是几何求解得到的 `nominal_nozzle_forward_ray_m`，不能使用相机Z深度。修正角直接加到执行器关节角。实测误差与容差、压力/泵设置、安装、几何标定、双目标定和本次编码器参考须能追溯。水流角度容差不得大于0.3°。页面只检查网格组合结构，不宣称完成独立验证覆盖、插值一致性或真实落点验收。

本页导出的行保持 `measured=false`，不会被后端当作已测水流表使用。原始实测证据完成审阅后，由已有 `FixedCameraLanding` 校验流程检查网格完整性、每单元内部独立验证、插值后的命令角、落点与编码器误差及全部绑定；不要直接批量把草稿布尔值改成true。

## 仿真的边界与验收

页面使用当前输入的转轴偏移、喷嘴方向和角度限位，求使喷嘴直线射线经过假设相机三维点的关节角。与现有几何模型同样采用水平+z、俯仰−y的串联旋转。超限、目标在相机后方、参数缺失或超距均拒绝，目标角不会被夹紧后当作成功。

仿真没有验证实际电机格点、反馈新鲜度、真实距离、水束宽度、水压和重力，因此不证明喷水命中。实机还需通过真实编码器、0.3°角度门槛和2mm射线门槛。选择实测补偿策略时还需独立水流校验；直线策略只检查几何对准。不能放宽门槛掩盖实际分辨率不足。

从 `ros2_ws` 运行本页回归：

```text
node --test tests/test_fire_commissioning.cjs
```

现有 `tools/preview_fixed_camera_calibration.py` 提供另一组固定安装假设的误差敏感性报告；它与本页预设尺寸不同，报告不代表实际标定。
