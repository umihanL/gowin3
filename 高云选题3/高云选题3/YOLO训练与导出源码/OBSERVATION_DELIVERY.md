# 六项楼前观察优化交付

> 本文是观察功能交付时的历史记录。用户之后已授权使用新融合数据重新训练，最新情况见[本次微调说明](OBSERVATION_RETRAIN.md)与[实时状态](TRAINING_STATUS.md)。

训练继续暂停在34个完整轮次，最佳权重来自第30轮。新增数据尚未训练；此次完成数据、程序、仿真与评估工具。

| 优化项 | 已实现 |
|---|---|
| 明确距离 | 0.4–1.0m可调；距离须关联当前目标，无有效测距时等待 |
| 分组评估 | 全量原验证集按距离、角度、像素和光照统计，另采40张独立条件验收图 |
| 有效像素 | 高≥40px、短边≥12px可调；插值放大不算新增细节 |
| 主动观察 | 到楼前停稳，云台扫描与对准；需要换位置时请求安全导航，不直接向目标行驶 |
| 多帧确认 | 同类同位置5帧中3帧；重复帧不计票，当前漏检、车辆移动、云台转动或输入过期撤销许可 |
| 针对性补样本 | 96个新位姿、192对双目，含暗光、斜视和3D局部遮挡；768张新增数据已融合 |

完整数据共5,064张图、47,778个框，训练/验证/测试为4,560/252/252张。源图、遮罩、最终标注、融合与离线浏览器检查通过；实际训练加载器逐一读取4,560张训练图，43,246个框全部保留，其中8,154个极小框也未丢失。标签完整不代表极小目标都能检出。

Python观察、双目深度与评估相关23项测试通过。C++上位机10组CTest通过，真实渲染消防和红绿灯流程均零碰撞完成。消防示例在0.5033m处获得41×35px目标、同目标5/5帧确认后喷射。

上位机目前是颜色规则与已知楼面几何的闭环演示；真实YOLO参考程序在`runtime/`，尚未量化部署为RDK X5 BPU模型。相机内外参与实际云台、测距反馈仍需要实机标定、接入和测试。

独立条件验收的指定火焰8/8、人物32/32检出，分别只覆盖2个和8个位姿。消防员在现有验证空间没有合格近景机位，不能给出其独立近景准确率。训练空间的消防员新图回放为预定目标12/12、全画面20/22，仅用于直观诊断。所有成绩来自原冻结模型，并非新增样本训练后的提高。
