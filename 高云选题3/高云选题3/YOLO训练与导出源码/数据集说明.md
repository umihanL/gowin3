# 融合数据与标注说明

最终数据统一位于 `dataset/`，类别固定为：火焰 fire、消防员 firefighter、普通人 person。消防员不会同时重复标成 person；同一窗口里重叠的火苗合为一个火焰实例。楼号、门牌、红绿灯本次不标为这三类。

旧 V1 的 600 对双目原图保留。新增 V6 一楼门头版 240 对，按原计划的采集区域、相机姿态和光照进行分层选择，其中 train/val/test 为 168/36/36 对。保留 `parent_pair_id`，不重新随机分割新图片。实际融合与去重后的数量以 `dataset/statistics.json` 和交付检查记录为准。

本次没有删除完整采集族。4 组像素完全相同的局部图像因配对/增强族需要而保留，均未跨 train/val/test，详见 `deduplication.json`。全套数据有 645 张无目标图片。总计 25,066 个框中有 17,397 个满足 `tiny` 分析条件；很多远处人物只有几像素，需结合云台对准、靠近重拍策略判断可识别距离，不能由标注数量推断识别精度。

双目左右两图均为 640×480。相机中点高 13 cm、基线采用 GS130W 标称 80 mm；水平视场 72°、理想校正针孔和零畸变是生成假设，尚不是这台 GS130W 实测的 K/D/R/T。左右相机的 K、变换矩阵、灯光与曝光写入每对原始 JSON。

标注依据实际渲染后的可见实例掩膜，包含墙体、窗框和视野裁切造成的遮挡。框为最小可见像素外接框，不是无遮挡投影框。像素坐标 `x0 y0 x1 y1` 的右下角为 exclusive，训练标签为 `class center_x center_y width height`，后四项按当前图宽高归一化。

每个可见实例都保留，包含一像素及边缘截断目标；`tiny` 定义为框短边小于 12 px 或可见面积小于 25 px，仅用于分析与筛选显示，不偷偷从标签中删除。无目标负样本保留空 `.txt` 文件，不伪造检测框。

新版源标注由旧源掩膜派生：独立核对三个新版立面与旧立面的像素差异只位于旧号码区域，11 个目标掩膜下的 RGB 像素不变，并核对新版纹理与冻结 GLB 内嵌纹理一致。派生记录没有冒称新版壁纸是旧绘图程序逐像素重新生成的。

每个 train 左右原图各增加一份成像增强，参数按双目对共享，噪声抽样按左右传感器独立生成。val 和 test 不加增强。原始渲染、增强图及跨版本同视点共用原采集组的划分约束。

`metadata.jsonl` 保留最终样本 ID、原样本 ID、源版本、父图、采集区域和姿态组、文件/像素 SHA-256、相机以及 mask 路径。当前活动路径相对完整训练工程，可搬移；历史快照里的原始元数据保留原绝对路径以追溯历史，不是训练程序的运行依赖。

未修改原 `AckermannRescueSim/ml/datasets/wallpaper_gs130w_v1`。训练包采用独立文件副本，避免编辑新包时通过硬链接改坏旧原图。
